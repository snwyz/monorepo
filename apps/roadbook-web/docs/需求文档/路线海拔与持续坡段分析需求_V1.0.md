## 1. 目标与产品边界

用户规划路线后，通过一张海拔面积图理解沿途起伏；默认全程，选择地图已有路段时同步该段。两个端点海拔相同，途中仍可能存在持续长坡，需在图上保留位置和按需读数。

仅提供道路的估算高程与起伏，不采集车辆参数，不计算电耗、回收电量、剩余续航或充电百分比；不表达实时路况、驾驶中预警或工程级路面测量，不自动改路。

当前公共Open Topo Data SRTM为试验接入，正式环境默认关闭；参数与地表高程尚未完成真实道路定版。实现及验收边界见[迭代记录](../迭代文档/2026-10-07-路线起伏与持续坡段分析迭代准备.md)。

## 2. 当前交付范围

- 用户明确要求直接使用已安装的Recharts，图上增加信息、图外减少区域；暂不设置详情入口。
- 一张距离—海拔渐变面积图，直接标注最高/最低点，轻量标记重点坡段；悬停/左右方向键展示公里、估算海拔、长坡长度和平均坡度。
- 默认全程，现有地图路段选择同步范围；地图只显示浏览位置，不主动聚焦。
- 有效点跨未知／低可信度缺口连接，面积同步连续；成功图表常驻“数据为实验室数据，仅供参考”，失败显示短提示和重试。连接仅用于展示，不补写缺失读数或改变统计。
- 移除范围工具栏、双端手柄、累计爬升/下降数字区、坡段目录、固定详情及数据说明入口。原有任意区间、累计指标和局部坡度计算保留在领域层，不作为当前界面入口。
- H5隐藏边界保持不变；真实道路精度与正式性能仍需独立验收。

## 3. 区间与方向语义

- 以同一有效路线版本的有向折线为分析对象。位置包含累计距离、路段 ID、路段内位置与经过序号，不能仅凭坐标去重。
- 自交、重叠道路和去返程中同坐标多次经过仍是不同位置。控制点位置以关联路段的连接边界确定，不对全程做最近点匹配后误选另一处经过位置。
- 任意区间作为保留的领域能力，终点必须位于起点之后；相同位置不能形成有效区间。当前无控制点选择器。反向行驶使用实际反向或返程道路，不倒置折线冒充返回路线。
- 默认分析当前单程。开启往返后按实际返回折线追加，终点同名时标为“返回起点”并保留经过序号；不额外绕环拼接区间。
- 开启往返复用去程已缓存的原始高程，仅查询返程新增采样坐标；同坐标的反向经过可复用读数，但不能合并里程、经过序号或上下坡统计。相同道路的反向采样位置若不一致，仍按新位置查询，不使用附近点推算读数。
- 曲线横轴始终采用从全程出发位置起算的累计公里数，地图路段范围切换保留这一口径。
- 边界不落在采样点时，只在连续有效样本内插值，不跨质量断点插值。跨控制点的长坡保持连续，控制点边界不是坡段结束条件。
- 开发前对照折线测距与供应商里程，明确海拔横轴口径及差异处理，不通过未经验证的比例拉伸掩盖几何问题。

## 4. 图表内容与领域指标

| 内容 | 当前展示要求 |
| --- | --- |
| 距离—海拔曲线 | 公里/海拔坐标，线性轮廓和渐变面积，不跨未知区域连接 |
| 最高/最低海拔 | 图内标注位置与数值；不完整时只代表已覆盖区间 |
| 重点坡段 | 轻量区间带标记位置；提示中显示上下坡、长度与平均坡度 |
| 累计爬升/下降、净高差、局部持续坡度 | 领域计算保留，当前不在面板展示 |

坡度百分比为升降高度除以水平行进距离再乘100。公里、米、百分比的显示精度按数据质量取舍，保留位数不代表精度。允许小幅反向起伏的持续上坡应区分净爬升与段内累计爬升。

## 5. 计算与识别策略

真实道路折线 → 坐标统一 → 按距离采样 → 查询高程 → 质量标记 → 去噪 → 多尺度坡度 → 连续坡段合并 → 区间统计。

- 分离原始高程、分析样本与绘图抽稀点。抽稀不能改变统计、控制点、峰谷、坡段边界和质量断点。
- 局部窗口识别较陡区间，趋势窗口识别缓长坡；不能仅由端点差或全段平均坡度识别起伏。
- 同方向坡段可合并。仅在距离与反向幅度都受限时容忍短平路或小幅逆向变化；明显反向坡、长平路和未知区间结束当前坡段。
- 重点坡段按行驶顺序排列；轻微起伏保留在曲线上，不强制全部进入目录。没有重点长坡不等于道路平坦。
- 区间裁剪后重新计算对应部分的长度、高差和坡度，不能沿用完整坡段的指标。
- 去噪不能把未知桥隧区间平滑成已知路面；缺失或低可信度区间不生成确定长坡提示。

### 5.1 试验参数与定版

| 参数 | 试验起点 | 定版条件 |
| --- | --- | --- |
| 采样间距 | 100m并保留控制点/断点，对照50m | 结合源分辨率验证坡段边界和累计指标稳定性 |
| 坡度窗口 | 局部500m、趋势2km | 验证盘山、平原与缓长坡的局部/趋势表达 |
| 平缓候选 | 趋势坡度绝对值约0.5%以下 | 校准噪声及低坡度长坡，不能单独据此判平缓 |
| 重点长坡候选 | 长度≥5km且净升降≥100m | 验证是否漏掉有意义的缓长坡，不作为通用长坡定义 |
| 短平路/反向容忍 | 距离与高度阈值待样例校准 | 防止碎片化和无界合并 |
| 异常与缺失 | 统计默认断开，图表可跨缺口连接；阈值待样例校准 | 缺失跨度与道路结构证据规则可复现，展示连接不补写海拔 |

以上是开发试验起点，未实测，不是生产标准或道路安全等级。集中策略与 `algorithmVersion` 管理参数；保存样例、误报/漏报、对照结果和定版理由，证据不足时保持试验状态。

## 6. 单图视觉与信息层级

沿用Roadbook暖白表面、近黑文字和灰阶。≤760px保持H5隐藏边界；761–1063px沿底部可用宽度铺开，左侧至少72px避让地图工具、右侧至少16px，最大920px；≥1064px以920px宽度水平居中。展开上限276px、标题48px，正文由图表占据，异步状态共用尺寸。761–1599px的右侧路线面板在海拔收起／展开时同步预留空间，保持12px间距，短窗口允许侧栏内容滚动。

- 标题“路线海拔 · 估算”与收起按钮，无额外摘要。
- 标题与内容统一使用外层毛玻璃，正文透明；面板不因悬停切换米白底色或跟随高光。鼠标点击图表不显示蓝色焦点框，保留键盘方向键浏览及冷灰键盘焦点提示。
- 两轴共同从零开始时，原点只显示横轴的一个“0”；仅省略重复纵轴标签，不改变刻度、网格或数据范围。负海拔与非零里程起点保留各自必要标签。
- Recharts单调平滑面积图：有效点使用`monotoneX`并跨缺口连接，中深绿2px轮廓配连续淡绿渐变向下淡出；保留原始读数、极值和领域统计，不向未知区间补写海拔。文字和控制保持灰阶，不用颜色暗示坡度或危险等级。
- 公里小刻度按显示跨度除以25后向上取1／2／5整值，500km每20km、1000km每50km；数字标签按绘图区宽度控制为最多六个，保留真实范围与全程累计口径。海拔取整值刻度与浅水平网格，最高/最低点标注向图内避让；平坦样例合并重复极值，单位单独标注。
- 空态以居中山形图标、主辅文案建立层级；加载态使用真实高程查询百分比和4px圆角细进度条，未知进度显示“准备中”，不伪造曲线。空态、加载、失败与图表正文高度一致。
- 长坡以弱中性带呈现，悬停/方向键显示具体数据；图内提示由库限制在可见边界内。
- 图外只允许不完整数据的短提示；不再提供范围、累计指标、坡段目录、详情或数据说明区域。

## 7. 交互与地图联动

| 操作 | 反馈与约束 |
| --- | --- |
| 首次打开 | 有有效桌面路线才查询，图表与异常状态使用同一正文高度 |
| 悬停/左右方向键 | 图内显示公里、估算海拔及所在长坡长度/平均坡度；地图只显示临时位置 |
| 选择现有地图路段 | 曲线范围同步该段，缓存有效时不重复查询 |
| 离开/失焦/收起 | 清除临时位置；不修改控制点，不算路，不主动平移地图 |
| Esc | 收起面板，不增加详情、目录或选区层级 |
| 方案/几何变化 | 隔离旧请求，清除旧位置；不引用旧路线曲线 |

浏览按绘制帧更新，不发网络请求。提示组件保持稳定身份，不能因重新挂载产生“定位后立即清空”的循环。自交/重叠路线仍按经过序号定位。

## 8. 数据接入与质量

### 8.1 候选方案与成本

推荐先评估独立高程服务，候选为 Open Topo Data + SRTM 30m；候选不代表已验证生产许可、精度与稳定性。

- 高德参考列有v2.1Beta及以上高程方法，当前仓库加载v2.0；覆盖、精度、视野外查询、地形加载条件、批量能力和授权待实测，不直接升级SDK宣称可用。[方法参考](https://lbs.amap.com/api/maps-javascript-api/reference/amap-map/map)、[地形教程](https://lbs.amap.com/api/javascript-api-v2/guide/map/3d-map)
- 本次腾讯公开路线字段核查未找到高程返回或通用批量查询能力，不否定未公开商业能力。[腾讯路线文档](https://lbs.qq.com/webservice_v1/guide-road.html)
- Open Topo Data要求WGS84并支持批量查询；公共服务每次最多100点、每秒1次、每天1000次。200km按100m采样约2001点，需21批，仅限流间隔约20秒，不能承诺即时生产响应。[接口](https://www.opentopodata.org/api/)、[额度](https://www.opentopodata.org/#public-api)
- SRTM约30m是水平采样尺度，不是垂直误差或路面精度；覆盖、空洞、测量年代、数据版本与高程基准待验证。[USGS说明](https://www.usgs.gov/faqs/where-can-i-get-global-elevation-data)
- 程序许可、数据许可与服务条款分别核验，记录商用展示、处理、缓存和归属要求；第三方查询只发送必要采样点，正式来源接入时提供适用的数据归属说明，不发送方案名或用户身份。

本轮仅形成需求，不新增收费服务、不安装工具、不下载全国栅格或部署服务。后续这些动作先说明成本与影响并取得明确授权。

### 8.2 坐标与基准

记录`coordinateSystem`并保留地图坐标与查询坐标对应关系，校验GCJ-02/WGS84转换，不把近似转换宣称为测量级精度。记录单位、垂直基准、分辨率、来源与版本；不同垂直基准未统一前不混合拼接。

### 8.3 状态与降级

| 状态 | 处理 |
| --- | --- |
| 无路线 | “路线生成后可用”，没有真实曲线 |
| 加载/处理中 | “正在分析沿线起伏”，等尺寸占位；进度只反映真实批次 |
| 有效 | “估算”，展示指标和重点坡段 |
| 局部缺失 | 图表跨缺口连接，底部统一“数据为实验室数据，仅供参考”；空值读数不可用，指标仍只统计有效区间 |
| 桥隧/高架疑似偏差 | 有可靠道路结构证据时标低可信度；证据缺失保留地表估算说明，不能声称所有桥隧已识别 |
| 失败 | 独立错误与重试，不阻断算路、编辑、暂存和外部导航 |
| 旧结果 | 同几何数据更新可显示“更新中”；几何变化立即清理旧联动，旧曲线不能代表新路线 |
| 没有重点坡段 | 不追加图外长坡摘要；仍展示起伏曲线，未知区域不参与判断 |

零米和负海拔可为有效值，不能自动视为缺失。未知区间不补零；曲线及面积允许在展示层跨缺口连接，连接不视为确定高程读数，不计算跨缺口爬升、不合并持续坡段。成功图表不再显示覆盖率，统一常驻用户指定的实验室数据参考文案；实际来源继续沿用试验性公共地表高程，文案调整不改变数据来源。

## 9. DDD职责与缓存

领域归于`domain/elevation-analysis`、基础设施归于`infrastructure/elevation-analysis`、视图归于现有`components/elevation-analysis`。以下为建议契约，按职责精简，不为名称增加空层。

| 对象/组件 | 职责 |
| --- | --- |
| `ElevationProfile` / `ElevationSample` | 保存采样、分析高程和质量 |
| `RouteElevationPosition` / `RouteElevationRange` | 表达有向经过位置与选区 |
| `SustainedSlopeSection` / `ElevationAnalysisPolicy` | 坡段规则与集中参数版本 |
| `ElevationProvider` | 隔离外部高程来源的领域查询接口 |
| `useRouteElevationAnalysis` | 编排请求、缓存、选区、坡段选择与地图联动 |
| `ElevationPanel` | 组合状态和视图，不计算路线和坡段 |
| `ElevationRangeSelector` / `RouteElevationChart` | 范围选择、绘图与曲线交互 |
| `ElevationRangeSummary` / `SlopeSectionDetails` | 区间指标、坡段详情与查看意图 |

结果至少关联方案ID、修订、路线几何签名、去返程范围、数据版本与算法版本；仅方案修订不足以区分供应商与实际返回路线变化。原始采样与分析缓存分开，按坐标转换、采样策略、来源、几何和参数真实依赖失效。

位置原始读数可在同一高程来源实例与来源版本内按精确坐标复用，缓存6小时且最多30000个位置；完整有向分析最多保留4份。成功批次独立保留，后续批次失败或任务取消不会丢弃已完成批次；未成功返回的坐标在下一次加载时补查，取消后迟到结果不得写入。重新组合不能延长旧读数有效期，主动重试绕过旧读数。进度只统计实际未缓存坐标的批次，全部读数已知时只进行本地分析；完整分析缓存命中时直接显示曲线，避免切换往返反复显示0%。

有效缓存内的范围切换不重新查询。完全相同的稳定几何可复用，不承诺每次编辑只更新一个路段。密钥、限流、归一化和服务访问由基础设施/服务端承担；地图只接收领域坐标与只读区间，SDK对象不进入Props。地图包维持ES2019，大样本达到阻塞预算时再评估工作线程。

## 10. 性能、可访问性与隐私

- 首屏不等待高程，首次打开有效路线卡片后按需查询；隐藏H5入口不触发请求。
- 图表与异常预留稳定空间，地图容器不变。LCP无回退且沿用桌面良好网络≤2.5秒目标，加载、选区与切换实测CLS目标为0。
- 分析密度独立于320px画布点数；绘图抽稀保留关键位置，不能为了绘图粗采样到漏掉长坡。
- 测量200km及1000km路线的点数、处理时间、首个有效结果、缓存选区切换与交互帧率，记录设备/网络/参数，未经实测不写通过。
- 曲线使用Recharts无障碍层支持左右方向键浏览；提供隐藏文本摘要，使屏幕阅读器可读长坡位置与长度。[HIG图表指南](https://developer.apple.com/design/human-interface-guidelines/charts)
- 核心控件命中目标≥44×44px；焦点可见，收起归还标题焦点。核心文字满足WCAG AA，上下坡、未知与选中不只靠颜色。
- 减少动态效果、减少透明度、增强对比度、强制颜色有实测回退；Web读取不到系统偏好时保持实色可读基础样式，不伪称系统设置自动生效。
- 普通日志不记录路线、坐标、方案名或密钥；缓存不成为新增云端路线仓储，不默认公开路线或增加位置跟踪。

## 11. 可复现样例与验收

合成剖面按距离生成连续采样；零噪声样例在实现约定的数值容差内验证，含噪声样例按定版策略验证，不用三五个控制点或抽稀图形替代算法输入。

| 样例 | 输入 | 预期 |
| --- | --- | --- |
| 同海拔长坡 | 0–20km为500m；20–55km线性升至1550m；55–90km线性降至500m；90–200km为500m | 净高差0，累计升降各1050m，35km上坡与35km下坡分别识别，平均坡度约±3% |
| 顺序反转 | 与前例统计相同，先下降后上升 | 目录与高亮顺序随方向变化，不能只复用汇总 |
| 跨控制点 | B在35km，A为0km、C为90km | AC沿B；长坡不在B切断，AB上坡裁剪为15km、450m |
| 任意沿线 | 前例选择30–45km | 长15km、净升450m、平均坡度3%，地图位置一致 |
| 裁剪起伏 | 前例选择30–70km | 累计升750m、降450m、净高差+300m，坡段裁剪正确 |
| 平原噪声 | 平坦基准加固定种子低幅噪声 | 定版策略抑制虚假长坡，不累加每个抖动 |
| 缺失与桥隧 | 加入无数据区与可靠结构标记 | 断开统计，不跨缺口合并，低可信度无确定长坡提示 |
| 重叠与返程 | 同坐标多次经过 | 按经过序号选区与高亮，不跳段 |

| 编号 | 通过条件 |
| --- | --- |
| ELEV-001 | 全程与已有地图路段可查看；原路线方向与几何不变，任意区间计算仍有领域回归 |
| ELEV-002 | 净高差为零仍能通过图内标记与提示读取长坡位置、长度、方向和平均坡度 |

## 12. 迭代顺序与执行门禁

| 阶段 | 退出条件 | 成本/风险 |
| --- | --- | --- |
| 数据可行性 | 小范围道路样例，来源/坐标/基准/许可/缓存/额度记录及选型 | 少量查询先验证覆盖与国内访问，不下载全国数据 |
| 领域算法 | 可复现样例，任意区间、持续坡段、质量策略和参数定版 | 去噪影响误报/漏报，证据不足保留试验状态 |
| 桌面界面 | Recharts单图、键盘浏览与图内提示、地图临时位置联动 | 图表密度和大样本实测，不增加首屏负担 |
| 独立验证 | 数据、实际浏览器、性能与规范一致性证据 | 最小相关验证；地图包变化先构建包再验证Web |

可在数据验证期间用显式演示数据开发领域与视图，但不作为用户路线结果。实际网络验证前说明样例数量与预计成本，收费、安装、下载大型数据、部署、commit/push等另遵守仓库授权与门禁。
