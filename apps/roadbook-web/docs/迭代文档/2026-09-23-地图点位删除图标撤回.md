# 地图点位删除图标撤回

## 1. 迭代信息

- 日期：2026-09-23
- 应用：`apps/roadbook-web`
- 目标：移除地图点位及定位标记旁的圆形删除图标，减少与编号、名称标签和定位图形的视觉冲突。

## 2. 关键决策

- 地图点位点击只更新选中状态和地图聚焦，不再创建删除入口状态。
- 删除能力继续通过 PC 地址列表图标、移动端 H5 左滑和 `Backspace` / `Delete` 提供。
- 所有保留的删除入口继续进入统一的二次确认流程，取消确认不改变路线数据。
- 不修改控制点、路线或本地方案的数据结构。

## 3. 功能变化

- 删除 `MapControlPointDeleteAction` 组件及其 Framer Motion 惰性加载逻辑。
- 删除 `RouteMap` 的地图删除入口 Props、覆盖层渲染和指针收起逻辑。
- 删除 `RoutePlanningWorkspace` 中仅服务于地图删除图标的状态。
- 删除地图删除图标专用样式。
- 地址列表、移动端左滑、键盘快捷键和删除确认框保持不变。

## 4. 验证要求

- 地图点位点击后只选中并聚焦，不显示圆形删除图标。
- 地址列表、移动端左滑和键盘快捷键仍能发起删除确认。
- TypeScript、ESLint、生产构建和 Git diff 格式检查通过。

## 5. 本次验证结果

- `roadbook-web` TypeScript 类型检查通过。
- ESLint 检查通过。
- Next.js 生产构建通过。
- Git diff 格式检查通过。
- 源码中已无地图删除图标组件、样式或专用状态引用。
