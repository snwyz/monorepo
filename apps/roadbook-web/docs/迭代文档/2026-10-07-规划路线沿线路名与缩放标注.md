# 规划路线沿线路名与缩放标注

> 当前状态（2026-10-10）：路名从 11 级开始显示，并按实际内芯宽度切换透明底与同色背景；方向箭头已关闭。首次实施记录保留如下，最新规则见文末补充。

## 目标与范围

借鉴用户提供的苹果地图截图，把有效规划路线的白色路名卡片改为直接沿线排布的文字。覆盖高德和腾讯 Web 地图、共享道路标签规则、正式 UI 与组件规范；不修改路线计算、方案存储、小程序及热门路线专题的编号图层。

## 问题与根因

原标签使用白底卡片和引导线，同名道路同屏只显示一次，无法表现截图中路名顺着道路方向、放大后长道路重复显示的效果。原绿色内芯宽 7px，也无法容下 12px 路名。旧候选只尝试整条道路的中点、四分之一和四分之三位置，长道路的这些位置在屏幕外时，可见部分没有标注。

## 关键决策与功能变化

- 保留 `roadSections` 数据契约，复用算路步骤中的真实道路名称与折线，不增加逆地址或道路查询请求。腾讯相邻步骤的端点可能不重复，按供应商原始索引连续性确认连接并合并同名道路，保留连接两侧的全部坐标；不以附近或距离相近推断连接。
- 整段路名保持 12px 字号、600 字重与正向阅读，按屏幕道路方向旋转。去程绿、返程蓝各使用自身内芯背景及深色细描边，文字下方的窄底层遮住原生箭头；两端其余方向箭头保留。
- 远景维持原线宽，12–14 级逐渐加宽，14 级及以上普通路线为白边 23px／边界 20px／内芯 16px，选中态各加 2px；旧结果、失败路线和插入引导保持原样。
- 先裁剪可见道路弧长，再生成基于道路起点固定相位的重复候选；间距至少约 280px，长名称增加间距。候选落在弯道时尝试附近平直位置，文字覆盖范围内的弯折不满足条件时跳过。
- 先分配不同道路，再补充长路重复；按视口面积限制数量，最多 32 个，每条道路最多 64 个候选。避让旋转后的文字范围、控制点、其他路名及屏幕边缘。
- 路名优先级与实际绘制顺序一致；被更高路线盖住的位置不绘制异色背景。腾讯选中路线最后绘制，与高德原有选中层级一致。
- 屏幕投影、旋转参数及折线样式更新留在供应商适配器。共享规则不依赖 React 或 SDK，继续遵守 ES2019。

## 性能与降级

不增加首屏请求、第三方依赖、动画或文档流元素。只有近景有效路线才排布路名；图像缓存有 256 项上限，标签和线宽签名未变时不重复更新。平移、缩放及尺寸变化结束后增量更新，腾讯同时监听 idle、panend 与 resize，不等待瓦片空闲才刷新，不重建地图，不通过 React 业务状态逐帧处理坐标。

缺名、过短、急弯、旧结果、失败路段及完全遮挡的位置不强行标注；少于 14 级不展示沿线路名。无供应商屏幕投影接口时使用现有平面投影降级。完整往返仍可能相互遮挡，不增加道路横向偏移。

## 验证结果

- `@roadbook/map` 的 ES2019 构建通过；地图包 39 项测试全部通过。共享规则覆盖沿线旋转、反向可读、长路重复、急弯避让、固定相位、控制点碰撞、路线遮挡与腾讯连续步骤合并。
- 两家适配器的隔离 SDK 测试覆盖原生旋转方向、固定图像尺寸、缩放线宽更新、旧结果及失败降级、覆盖物清理与事件解绑；腾讯另验证仅触发 panend 时也能更新。
- Roadbook Web 的 ESLint 和生产构建通过，生产构建使用独立且被忽略的输出目录。构建自动加入的类型路径已恢复，临时验收按钮已移除。
- 使用本地真实高德、腾讯 SDK，在 1280×800 桌面视口与 390×844 手机视口验收都江堰景区至青城山旅游区路线。已观察到道路文字随道路旋转、长道路重复呈现、缩放后字号保持稳定，以及去程绿／返程蓝和平移后的更新；保存腾讯手机效果截图。
- 保留本次开始前已有的默认单程、按需返程等改动；没有执行提交、push 或部署。

## 已知边界与后续建议

- 首版为整段文字随道路方向旋转，不做逐字曲线排版；没有足够平直空间时保留清晰路线并跳过路名。
- 未知名称不会从 POI、控制点或附近道路推测。
- 不将不改变文档流或局部截图当成完整页面 LCP 达标、CLS=0 的证据；真机性能和触摸验收仍需独立测量。
- 腾讯 SDK 仍报告既有超充图钉 normal／selected 样式宽度告警，来自非道路路名图层，本次未修改该图层的尺寸。

## 11 级路名与窄路线适配（2026-10-10）

- 目标与范围：将 `LABEL_MIN_ZOOM` 从 14 改为 11，提前显示有效路线的真实道路名称，适配高德与腾讯的普通、选中、去程及返程路段。
- 问题与根因：11–12 级普通路线内芯仅 7px，原有固定 16px 实色背景会凸出路线；原适配器签名未包含图像样式，可能在位置不变时跳过背景刷新。
- 关键决策与功能变化：保持 12px 白字与 1.5px 深色细描边。实际内芯不足 16px 时使用透明底，达到 16px 才绘制同色背景；共用现有缩放线宽，不额外增宽路线。缓存键与两家适配器的更新签名包含背景样式。
- 降级与密度：保留缺名、过短、急弯、遮挡、控制点碰撞与屏幕边缘过滤；重复间距、256 项图像缓存及同屏最多 32 个标签保持原值。低于 11 级隐藏，不增加道路查询或方向箭头。
- 文档同步：更新正式 UI、组件规范与 Web 上下文，同时将近景选中线宽说明校正为源码现有的 31／27／21px。
- 验证结果：地图包 ES2019 构建通过；既有路名规则与两家适配器测试共 22 项通过，覆盖 10.99 级隐藏、11 级显示、11–14 级背景切换、选中状态切换、缓存隔离及既有避让。Web ESLint、生产构建（含类型检查）与差异空白检查通过；构建改写的 `next-env.d.ts` 已恢复。真实地图浏览器验收待本次插件授权。
- 已知边界与后续建议：11 级文字可能跨过较细的路线内芯，透明底避免实色矩形扩宽，细描边辅助阅读；真实底图对比度、桌面与手机视觉密度仍需浏览器验收，不将构建或模拟 SDK 测试视为视觉与 LCP／CLS 验收完成。
