# 中等屏幕工作台布局修复

## 目标与范围

修复 760–1180px 附近的工作台面板错乱，保留 760px 及以下的 H5 底部任务面板。修改工作台组合与布局样式，同步正式 UI、组件规范；不修改地图适配器或算路规则。

## 问题与根因

- 中等宽度将地址列表顶边距从 88px 改为 156px，但仍独立使用 50dvh 最大高度；底部摘要独立定位，较矮视口中两个区域相交。
- 海拔栏在中等宽度改为 left: 16px，与地图工具占用同一区域，390px 最小宽度又限制了收缩。
- 专题目录没有同步避让第二行顶部入口。
- 地址列表加载占位按点数设置 min-height，无法服从剩余可用高度。

## 关键决策与功能变化

- 用 `workspace-route-panels` 组合路线顺序和摘要，共享桌面侧栏高度。摘要保持自然高度，列表正文滚动，卡片间保留至少 12px；该规则也解决 >1180px 矮窗口的同类重叠。
- 原有 WorkspaceSheetPage 的业务激活条件保持不变，手机端外层为 display: contents，继续复用同一组件树。
- 中等宽度海拔栏左边距改为 72px，取消固定最小宽度，给左右工具和业务面板留出空间。
- 专题目录顶边距统一为 156px；加载占位改用可收缩的 height。

## 降级策略

空间不足时优先缩小地址正文的可滚动区域，保留摘要与列表头尾。地图失败、路线计算中和失败态沿用现有提示与重试入口，不引入额外网络请求或依赖。

## 验证结果

- Browser 实际加载本机已有三点路线，在 761、900、1000、1180、1181px 宽度检查元素边界；624px 高度下卡片间距均为 12px，无页面横向溢出。1000px 另验证 700px 高度。
- 761×624 下检查搜索展开与关闭、完整路线和选中路段摘要；海拔栏右边界 405px，右侧卡片左边界 421px；地图工具右边界 60px，海拔栏左边界 72px。
- 760×624 验证手机路段详情及返回路线根页面，继续使用单一底部任务面板。
- `pnpm --filter roadbook-web lint` 通过。
- `pnpm --filter roadbook-web build` 通过；恢复构建自动修改的 next-env.d.ts 开发声明路径。
- `git diff --check` 通过。环境未安装 rtk，使用原生 pnpm/git 执行对应检查。

## 已知边界与后续建议

- 本轮验证聚焦布局和已有路线，不覆盖重新创建五点路线、全部专题操作或真机触摸与软键盘。
- 本次只增加 CSS 布局容器，不增加首屏请求、运行时尺寸测量或 hydration 后组件替换；未重新采集生产 LCP/CLS，不宣称性能指标全部达标。
- 后续如支持极矮横屏，应单独定义完整工具栏与侧栏的最小可用高度。

## 后续调整：PC 策略合并到路线顺序

根据用户反馈，将 PC 的策略下拉合并至路线顺序标题栏，与标题和数量同一行；移除原独立策略卡片、正常暂存信息和撤销按钮。H5 保留原策略区域、暂存状态、撤销及排序，不调整业务操作。此次决策替代前文规划模式的 156px 顶边距：所有 PC 宽度的规划侧栏统一从 88px 开始；专题目录仍避让专题入口。

- `RouteAddressList` 增加策略控件插槽；`RouteStrategySelector` 增加紧凑呈现，两端共享选项与策略修改回调。
- 0 点方案也提供 PC 策略标题栏，避免隐藏独立卡片后失去入口；H5 的空列表仍隐藏。
- 不再展示正常暂存反馈，计算和暂存失败仍在 PC 标题栏提供文字提示，计算中沿用地图已有反馈。自动暂存与撤销业务能力保持，H5 按原入口使用。
- 浏览器验证 1000px PC 标题栏与下拉；切换“非高速／国道参考”并恢复“推荐路线”，761px 下长名称、标题及数量同排且无溢出；760px 下仅一个可见策略下拉，暂存成功提示与撤销按钮仍可见。
- lint、生产构建和 diff 空白检查通过；未新增依赖、网络请求或按视口挂载的业务树。LCP/CLS 与真机验证边界沿用前文说明。

## 空间重构：WWDC 风格的连续侧栏

### 目标与根因

此前只解决卡片碰撞，路线入口、搜索、列表、摘要仍呈散落浮层；同一任务重复使用玻璃外壳，底图透入列表，影响信息层级。用户要求针对该屏幕区间重新设计空间。

### 最终布局决策

本节替代前文 761–1180px 的分离卡片布局，正式尺寸以 UI 规范 5.2.1 为准。

- 搜索固定左上地图区域；我的路线置于右上，与 324px 侧栏对齐。
- 路线顺序、策略、地点列表和摘要收进一块从 88px 到视口底部 24px 的连续侧栏。列表使用剩余高度，摘要固定在底部，以分隔线建立分组。
- 外层保留轻量材质、22px 圆角，列表和摘要取消独立模糊、阴影及边框；地址行取消普通描边，保留选中与导航语义。
- 海拔入口缩为不超过 320px 的底部辅助控件。搜索、天气及其加载占位按地图区域限宽；专题目录也与侧栏边界对齐，隐藏重复的顶部专题徽标。
- 不改变 H5、宽屏的业务结构、策略选项、暂存或撤销行为，不新增依赖和运行时测量。

### 参考与降级

项目专用 Apple 评审 Skill 未安装，采用正式规范及 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 的层级与材质分工原则。无 backdrop-filter 时使用浅色实底；减少透明度与强制颜色模式有对应降级。

### 验证结果与边界

- Browser 检查 761、900、1180px × 624px，1000×700px：方案与侧栏左右对齐、列表与摘要连续无重叠，无横向溢出。
- 761×624px 天气卡片范围 x=16–405，侧栏从 x=421 开始；搜索展开同样限制在地图区域。
- 760px 保留 H5 任务面板；1181px 恢复原桌面独立卡片布局。
- lint、生产构建、git diff --check 通过；恢复 next-env.d.ts 的开发类型声明路径。
- 本轮未验证全部专题操作、真机手势和生产 LCP/CLS；不将 CSS 调整等同于完整性能达标。

## 最终推广：所有桌面宽度统一连续侧栏

用户认可连续侧栏设计后，要求将其推广到全部 >760px 视口。本节替代前文中 1180px 以上恢复旧布局的约定。

- 删除 1180px 的布局分支，所有桌面统一左上搜索、右上方案入口与 324px 连续侧栏。
- 宽屏增加地图空间，侧栏、摘要与工具尺寸不拉伸；海拔入口统一左边距 72px，天气与其占位统一从地图区域左侧展开。
- 同步减少透明度及强制颜色降级规则，H5 的布局和交互不变。
- Browser 实测 761、1180、1181、1440、1920px × 900px：入口与侧栏对齐、列表和摘要连续、侧栏均为 324px，无横向溢出；760px 回归确认原撤销入口仍可见。
- lint、生产构建、git diff --check 通过，构建改写的 next-env.d.ts 已恢复。未增加请求或依赖，性能实测边界沿用前文。
