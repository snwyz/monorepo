# 地图控制点名称标签迭代

## 1. 迭代信息

- 日期：2026-09-23
- 应用：`apps/roadbook-web`
- 地图领域包：`@roadbook/map`
- 目标：参考用户草图，为地图上的每个控制点增加编号与地点名称标签。

## 2. 范围

- 每个控制点显示编号徽标和地点名称。
- 标签通过引导线连接控制点真实坐标。
- 奇数和偶数编号分别向右、向左展开，降低连续标签重叠概率。
- 当前选中标签使用反色和加粗描边表达状态。
- 高德与腾讯地图使用同一套标签视觉与名称截断规则。
- 不增加地图服务请求，不改变控制点、路线和本地方案数据格式。

## 3. 关键决策

### 3.1 单一控制点 Marker

“编号＋地点名称＋引导线”标签作为控制点唯一 Marker，同时负责视觉呈现、点击选择和选中状态。原有圆形编号 Marker 及其独立图层被移除，避免同一控制点重复显示编号。

### 3.2 统一视觉生成

`@roadbook/map` 内的 `createControlPointLabelVisual` 负责生成内容宽度自适应的 SVG、引导线、编号徽标、名称截断和选中态。高德适配器使用 Marker 内容与 Pixel 偏移定位，腾讯适配器使用独立 `MultiMarker` 图层和自定义 Anchor 定位。

### 3.3 稳定布局

标签保持 `64px` 画布高度和 `36px` 胶囊高度，宽度按照“编号徽标、间距、实测文字宽度和右侧内边距”动态计算，短名称不保留无意义空白。奇数点向右展开、偶数点向左展开；名称最多显示 `10` 个字符。地图平移、缩放或路线更新只更新覆盖物，不改变页面布局，目标 CLS 为 0。

## 4. 功能变化

- `WebMapControlPoint` 增加地点名称字段。
- 高德地图新增控制点标签覆盖物集合，并在画布销毁时释放。
- 腾讯地图新增控制点标签 `MultiMarker` 图层，并在画布销毁时释放。
- 控制点选中、排序或名称变化时同步重绘标签。
- 标签 Marker 继承原圆形 Marker 的点位点击事件；路线点击和定位点保持不变。
- 原圆形编号 Marker 及其 SVG 生成逻辑被移除。

## 5. 降级与边界

- 首版使用稳定的左右交错规则，不执行全局碰撞计算；控制点非常密集时仍可能局部重叠。
- 超过 `10` 个字符的名称使用省略号，完整名称在路线地址列表中查看。
- 标签依赖地图 SDK 覆盖物定位；地图供应商切换时由新画布重新创建，不复用旧 SDK 对象。

## 6. 验证要求

- `@roadbook/map` 类型检查与构建通过。
- `roadbook-web` 类型检查、ESLint 与生产构建通过。
- 高德与腾讯地图均显示全部控制点标签，编号、名称和真实坐标一致。
- 点击标签后控制点被选中且标签反色，不再出现重复圆形编号 Marker。
- 标签范围外的地图拖动、缩放、双击选点和路线点击保持原行为。
- 地图供应商切换后标签完整重建，旧标签图层被释放。
- Git diff 格式检查通过。

## 7. 本次验证结果

- `@roadbook/map` 类型检查与构建通过。
- `roadbook-web` 类型检查、ESLint 与生产构建通过。
- Git diff 格式检查通过。
- 高德与腾讯地图共用同一标签视觉生成器；单一标签 Marker 的创建、点击、更新及销毁链路均已完成静态复核。
- 真实地图上的遮挡、缩放和平移体验仍需在获得浏览器操作授权后进行页面验收。

## 8. 标签宽度修正

根据真实页面反馈，取消固定 `160px` 胶囊宽度。标签现在使用 Canvas 字体度量获取截断后名称的实际宽度，再叠加编号徽标、间距和右侧内边距；无法使用 Canvas 时采用按字符类型估算的稳定降级值。标签保持固定高度和最小宽度，高德与腾讯地图继续共用同一视觉结果与动态锚点。

本次修正已通过 `@roadbook/map` 类型检查与构建、`roadbook-web` 类型检查、ESLint、Next.js 生产构建及 Git diff 格式检查。

## 9. 原圆形 Marker 撤回

根据真实页面反馈，移除坐标处原有圆形编号 Marker，仅保留自适应宽度的“编号＋地点名称＋引导线”标签。标签 Marker 直接绑定原有控制点选择回调：高德使用标签 Marker 的点击事件，腾讯使用单一 `MultiMarker` 图层的几何 ID 回传控制点 ID。

本次调整已通过 `@roadbook/map` 类型检查与构建、`roadbook-web` 类型检查、ESLint、Next.js 生产构建及 Git diff 格式检查。
