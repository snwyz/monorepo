# 路线里程指标命名迭代

## 1. 目标

让路线摘要中的里程名称与当前展示范围一致，避免“预计里程”无法区分完整环线和单个路段。

## 2. 范围

- 完整路线摘要将里程指标命名为“环线里程”。
- 选中路段摘要将里程指标命名为“路段里程”。
- 里程计算、单位格式、预计驾驶时间和数据来源说明保持不变。

## 3. 关键决策

`RouteMetricsPanel` 根据是否存在有效选中路段派生里程标签，不新增组件状态。摘要底部继续显示“预计值仅供参考”，明确环线与路段里程仍来自地图供应商的估算数据。

## 4. 性能与布局

本次只替换稳定文本，不新增请求、依赖、资源或异步状态。指标区域沿用既有布局，不改变首屏资源链路，也不引入新的 LCP 或 CLS 风险。

## 5. 验证结果

- `roadbook-web` TypeScript 检查通过。
- `RouteMetricsPanel` ESLint 检查通过。
- `git diff --check` 通过。
- 实际页面中的完整环线与选中路段文案保留为手工验收项。
