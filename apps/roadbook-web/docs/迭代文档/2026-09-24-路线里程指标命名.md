# 路线里程指标命名与切换迭代

## 1. 目标

让路线摘要中的里程与驾驶时间使用一致的展示范围，并允许用户在完整路线中比较往返和单程数据。

## 2. 范围

- 完整路线摘要默认显示“往返里程”和“往返用时”，点击里程指标后同步切换为“单程里程”和“单程用时”，再次点击恢复。
- 选中路段摘要将里程指标命名为“路段里程”。
- 往返里程与用时包含全部闭合路段；单程里程与用时不包含最后一个控制点返回起点的返程段。
- 完整路线摘要标题将“`N` 个控制点”调整为“`N` 个坐标”，并移除右侧重复的“路线有效”标记。
- 单位格式和数据来源说明保持不变。

## 3. 关键决策

`RouteMetricsPanel` 使用本地展示状态切换往返与单程口径。单程里程和用时分别汇总最后返程段之前的已有路段，不新增地图请求；选中具体路段时固定使用该路段数据，避免混淆。指标区域使用原生按钮语义、可见焦点和状态说明，摘要底部继续显示“预计值仅供参考”。

摘要标题中的“坐标”仅作为用户界面文案，领域模型和组件接口继续使用 `ControlPoint`，避免展示措辞影响领域命名。移除“路线有效”后保留原有标题高度，不改变 Widget 布局。

## 4. 性能与布局

本次不新增请求、依赖或资源。切换状态仅存在于已加载组件中，指标区域保持原有尺寸，不改变首屏资源链路，也不引入新的 LCP 或 CLS 风险。

路线摘要的里程与驾驶时间统一使用固定的标签行高和数值行高，确保中英文混排、数字与单位使用不同字形时仍保持两列基线对齐；该调整不改变 Widget 尺寸和指标语义。

## 5. 验证结果

- `roadbook-web` TypeScript 检查通过。
- `RouteMetricsPanel` ESLint 检查通过。
- `git diff --check` 通过。
- 往返/单程切换实现再次通过上述类型、组件规则和差异格式检查；实际点击、键盘操作以及选中路段后的固定文案保留为手工验收项。
- “坐标”文案与“路线有效”移除再次通过上述检查，源码中已无该状态标记及其专用样式。
- 路段里程与预计驾驶两列使用相同的 `16px + 22px` 文本行轨道，标签和数值基线保持对齐。
