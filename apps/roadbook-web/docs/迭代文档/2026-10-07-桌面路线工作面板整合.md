# 桌面路线工作面板整合

## 目标与范围

按用户确认的设计，将独立的方案入口及目录与路线编辑侧栏整合为一个工作面板，复用移动端业务导航。范围为工作台页面组合、方案选择器受控状态、页面可见标记、侧栏与沿途设施样式，以及对应产品、UI、组件规范和 AI 工作入口。

## 问题与根因

原桌面方案目录作为顶部独立浮层，路线编辑和摘要另占一个连续侧栏。两个容器各自承担当前路线信息，目录展开时会遮住编辑区；移动端已有任务切换机制，桌面却一直展示多个业务页面。上轮将新建入口前置后解决了创建的可发现性，但没有统一目录与规划的导航层级。

## 关键决策与功能变化

- 桌面工作面板宽 324px，顶部 16px，高度随内容收紧且不超过视口高度减 40px，固定 56px 标题栏同时承载方案切换与新建；正文在目录、规划、地点、路段、超充详情及既有专题之间切换。
- 初次进入显示本机目录；目录读取中与空状态分开提示，不预先创建方案、不自动加载历史路线、不额外读取候选方案快照。
- 目录状态由工作台业务导航控制，选择器通过 `open/onOpenChange` 提交导航意图；活动任务存在时可返回当前规划或指南。浏览目录不会清除活动路线、地图选择和设施图层。
- 目录及详情隐藏规划列表，目录、地点和超充详情隐藏里程摘要；路段详情显示对应路段摘要。选择或新建后回到规划视图。
- 方案列表与规划列表保持挂载；规划列表在超充详情期间也不再卸载，保留已有排序、选择及滚动容器。已验证目录与规划往返保留活动路线；长列表滚动恢复仍待专项验收。
- 新建及添加途经点直接复用原回调。全部清除仍经过确认，完成后保留空目录并清理管理、重命名状态；本轮未执行实际清除。
- 工作面板外壳使用既有共享玻璃 Token，标题、目录、规划、摘要、天气和专题内层关闭重复模糊；沿途设施取消独立卡片外壳，压缩为紧凑工具区并保留状态和重试。
- 桌面地点详情复用手机端地址、导航和删除操作组，天气与按需加载占位进入同一面板；地点详情在地址上方明确提供左箭头与“返回当前路线规划”；路段详情提供返回当前规划入口，充电站继续使用原详情关闭操作。
- 桌面末尾添加途经点紧随最后一个点，间距 8px、按钮高 44px；短目录与规划不再拉满大屏。返回箭头置于文字左侧。新建规划保持 104×44px，以 1px 银灰细边及内侧高光形成金属边界，并保留系统实色降级。
- H5 保持同一业务组件树与原任务面板档位，桌面可见标记独立于 H5 的 `active` 标记；不按视口重新挂载地图或业务树。

## 降级策略与性能范围

- 延续共享材质的实色、增强对比度、强制颜色和减少动态效果回退。
- 保留定位、路线、天气、设施查询原有错误、重试与过期结果隔离机制。
- 不增加运行时依赖、字体、图片或首屏业务请求；固定面板宽度与标题尺寸，面板自然高度受视口上限约束，超长内容内部滚动。地图实例与地图容器没有改动。
- LCP 无回退和 CLS 为 0 是验收目标，本轮静态检查与构建不能代替实际页面性能测量。

## 验证结果

- 最终源码的 Web ESLint、TypeScript 检查通过，差异格式检查通过。
- 使用 `.next/unified-panel-validation` 隔离目录完成 Web 生产构建，页面和 API 路由生成成功；已恢复构建自动改写的开发声明及 TypeScript 配置。
- 最终差异静态复核：无活动任务时派生目录；目录仅显示标题和目录正文；规划显示编辑与摘要；地点和超充分别显示详情；路段只显示路段详情与摘要；专题沿用原业务内容。
- 用户已授权本轮内置浏览器验证。已验证初次目录、已有路线加载、目录与规划往返、末尾添加打开和关闭搜索、地点天气与显式返回、删除确认取消。未执行删除、清除或新建定位请求。
- 1280×800 与 1280×1400 的两点规划面板均高 623.5px，末点与添加按钮间距 8px；1280×480 时面板内部滚动且摘要保留在安全视口内。390×844 H5 规划与 320×740 H5 目录、返回行为通过，无横向溢出。
- 最新新建按钮实测 104×44px、1px 银灰边界与内侧高光；地点详情返回按钮通过 Enter 激活，原两个控制点与路线摘要恢复，控制台未发现 error。
- 页面证据保存于验证截图目录：PC路线目录整合、PC大屏路线面板收紧、PC路线末点添加、PC地点详情明确返回、H5路线面板回归。

## 已知边界与后续建议

- 新建精确定位、路段详情、超充详情、重命名、空目录和长列表滚动恢复尚未完成专项交互验收，不将静态复核等同于这些用例通过。
- H5 应复核发现页、路线目录、规划与详情切换，确认档位与滚动位置保留。桌面窄视口不能替代 iOS/Android 真机触摸与软键盘验收。
- 内层滤镜展平和固定尺寸降低额外绘制与布局变化风险，但仍需实际 LCP、CLS、地图可用时间和真机帧率证据。
