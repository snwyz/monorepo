# 高德与腾讯地图切换迭代

## 1. 迭代信息

- 日期：2026-09-22
- 状态：开发与自动化验证完成，待人工浏览器视觉验收
- 应用：`apps/roadbook-web`
- 地图领域包：`@roadbook/map`
- 目标：默认接入高德地图，并在页面右下角提供高德地图/腾讯地图 Switch，使用户可以在不丢失路线方案的情况下切换完整地图供应商能力。

## 2. 范围

- 新增高德地图 JavaScript API 2.0 适配器。
- 新增高德地点搜索、逆地址解析、IP 定位、坐标转换和驾车算路代理。
- 新增高德 JavaScript API 同源安全代理，`AMAP_SK` 仅保留在服务端。
- 将 Web 地图组件与应用 Hook 从腾讯具体类型调整为供应商无关接口。
- 页面右下角新增高德地图/腾讯地图 Switch，默认高德。
- 供应商切换后重新创建地图并重新计算当前活动路线。
- 小程序与后端行政区同步不在本次范围内，继续保持现有腾讯实现。

## 3. 关键决策

### 3.1 完整能力切换

Switch 不只替换底图。地点搜索、双击选点后的逆地址解析、定位坐标转换和闭合驾车算路全部跟随当前供应商，避免不同来源数据混用。

### 3.2 领域接口隔离

地图包新增 `WebMapAdapter` 和 `WebMapProvider`。`AmapWebAdapter` 与 `TencentMapWebAdapter` 实现同一契约，`RouteMap` 只接收领域接口，不暴露 SDK 对象。

### 3.3 默认值与持久化

页面每次进入都默认高德地图。本次不保存用户上次供应商选择，确保“默认高德”语义稳定，也不修改现有路线方案快照格式。

### 3.4 高德密钥安全

- 当前环境只需要以下两个变量，不需要新增 WebService 专用 Key 或 SK：

```dotenv
NEXT_PUBLIC_AMAP_KEY=<高德 Web 端 JS API Key>
AMAP_SK=<该 Key 对应的 securityJsCode>
```

- `NEXT_PUBLIC_AMAP_KEY` 仅用于加载高德 Web 端 JavaScript API。
- `AMAP_SK` 作为对应 `securityJsCode`，只由 Next.js 服务端读取。
- 浏览器通过 `/_AMapService/*` 同源代理完成高德 JavaScript API 安全校验。
- 业务 WebService 通过 `/api/amap/*` 服务端路由访问，不在浏览器中拼接或打印安全密钥。
- WebService 开启数字签名时，服务端检测到 10007 后自动按参数名升序生成 MD5 `sig`，并在后续请求中复用数字签名模式。

## 4. 功能变化

### 4.1 地图工作台

- 首次进入显示高德地图。
- 右下角固定展示“高德地图/腾讯地图”双标签 Switch。
- Switch 关闭态为高德，开启态为腾讯；当前供应商同时通过文字字重表达。
- 切换期间 Switch 进入禁用等待态，但保持固定尺寸，不引起布局偏移。

### 4.2 路线与异步隔离

- 切换供应商时递增路线计算版本，旧供应商晚返回的结果会被忽略。
- 旧地图画布销毁后释放覆盖物和事件监听。
- 控制点与路线方案继续保存在原有领域模型和本地仓储中，不因切换丢失。
- 新供应商就绪后使用相同控制点和策略重新计算闭合路线。

### 4.3 高德路线策略

| 领域策略 | 高德策略码 |
| --- | --- |
| 推荐 | `10` |
| 高速优先 | `20` |
| 不走高速 | `13` |

高德返回耗时以秒为单位，适配器统一转换为领域模型的分钟；折线路径由各步骤的 `polyline` 合并，并去除相邻重复点。

## 5. 降级策略

- 高德未配置或连接失败时保留路线方案，显示高德地图不可用信息，用户仍可切换腾讯地图。
- 腾讯地图未配置或连接失败时采用同样处理，不自动静默回退，避免界面供应商标识与实际数据来源不一致。
- IP 定位失败时仍以默认中心创建地图；浏览器精确定位失败时优先保留已有城市级位置。
- 逆地址解析失败时保留坐标并显示“未识别地址”，不阻断算路。

## 6. 性能与布局

- 高德 SDK 与腾讯 SDK 均按当前供应商异步加载，不同时进入首屏关键资源链路。
- 地图容器与 Switch 使用固定尺寸和绝对定位，供应商切换不改变页面文档流，目标 CLS 为 0。
- Switch 使用项目内轻量基础组件，没有增加新的运行时依赖。

## 8. 已知边界与后续建议

- 高德 Web 端 Key 必须与 `AMAP_SK` 对应，并配置正确的来源白名单和服务权限。
- 地图服务额度、QPS 和商业授权仍由各供应商控制。
- 供应商选择当前不持久化；若未来需要记忆选择，应作为独立产品决策并保证首次用户仍默认高德。
- 建议后续为两个适配器补充统一契约测试，以及代理接口的响应字段测试和限流策略。
