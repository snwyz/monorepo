# 全屏地图工作台整页缩放策略

## 目标

让 Roadbook Web 按全屏地图 App 式工作台运行，避免浏览器整页缩放改变地图与浮动 Widget 的整体视口关系。

## 范围

- 通过 Next.js viewport 元数据限制整页缩放。
- 保留地图自身的滚轮、触摸手势和地图工具按钮缩放。
- 同步 UI 设计规范中的交互基线。

## 关键决策与功能变化

- `viewport` 设置 `maximumScale: 1` 和 `userScalable: false`；页面初始缩放仍为 1，并保留 `viewport-fit=cover`。
- 桌面端地图缩放继续由地图滚轮和工具按钮控制；移动端地图缩放继续由地图触摸手势和工具按钮控制。
- 限制浏览器整页缩放是工作台交互选择，不代表地图渲染性能会因此提升。

## 问题与根因

全屏地图和浮动 Widget 共同构成单页工作台。浏览器级整页缩放会缩放整个视口内容，和地图自身缩放属于不同层级；此前 viewport 未表达禁止整页缩放的产品策略。

## 降级策略

浏览器或系统辅助功能可能覆盖 viewport 缩放限制；地图自身缩放控件仍提供明确的地图缩放入口。

## 验证结果

- 静态确认 Next.js viewport 元数据包含 `maximumScale: 1` 与 `userScalable: false`。
- 未进行真机浏览器矩阵验证；整页缩放限制的实际执行仍受浏览器和系统设置影响。

## 已知边界与后续建议

- 该改动不降低地图瓦片加载、地图图层绘制或路线更新的计算量，不能作为地图卡顿修复。
- 若后续出现缩放相关卡顿，应区分浏览器整页手势和地图 SDK 缩放操作后，再按对应渲染链路排查。
