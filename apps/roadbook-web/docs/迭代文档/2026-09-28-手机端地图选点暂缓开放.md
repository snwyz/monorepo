# 手机端地图选点暂缓开放

## 目标与范围

按当前产品要求，手机端地图点击新增途经点的交互暂缓开放，等待进一步评估。范围为 Roadbook Web 的手机布局（视口宽度 ≤760px）。

## 问题与关键决策

原实现由高德、腾讯地图的双击事件统一调用 `RouteMap.onDoubleClick`，未区分手机与桌面。现在在回调执行时检查当前视口，手机端直接返回，并留下待评估注释；保留原业务处理，后续可恢复。按事件实时判断，窗口跨越断点无需重建地图。

## 功能变化与降级策略

- 手机端双击地图不再新增途经点，也不再通过该共享入口新增专题个人标记。
- 手机端使用地点搜索添加；已有地图点位选择、天气、路段选择及拖拽插点沿用现有行为。
- 桌面端双击选点继续可用，地图包和 SDK 事件注册不变。
- 同步产品、UI 与组件规范；本次手机端限制优先于历史记录中的通用双击选点描述。

## 验证结果

- `pnpm --filter roadbook-web lint`：通过。
- `pnpm --filter roadbook-web build`：通过，包含 TypeScript 校验。
- `git diff --check`：通过。
- 环境未安装 `rtk`，使用等价原始命令验证。
- 已尝试 Browser 页面验收，但浏览器连接连续两次失败，未完成实际页面和真机触摸验证。

## 已知边界与后续建议

手机端以现有 760px 响应式断点定义。横屏超过该断点时沿用桌面行为。未新增资源、请求或布局结构，未实测 LCP、CLS。后续确认地图选点交互后再决定恢复入口；补验高德、腾讯在手机视口双击不增点、桌面双击可增点，以及跨断点切换。
