# 移动端路线规划布局迭代

## 1. 迭代信息

- 日期：2026-09-23
- 状态：实现完成，最终交互已确认，移动端手工验收由用户执行
- 应用：`apps/roadbook-web`
- 目标：重新排列移动端地图工作台的任务优先级，突出路线顺序与逐段导航，并减少默认展开面板对地图的遮挡。

## 2. 范围

- 搜索固定到底部安全区，搜索结果向上展开。
- 移动端隐藏地形分析。
- 地图供应商切换改为右侧贴边图标，点击后向左展开。
- 路线顺序面板固定在搜索上方，每个有效路段增加导航图标。
- 外部导航按当前地图供应商生成高德或腾讯官方 URI。
- 移动端方案欢迎面板默认隐藏，通过顶部“我的路线”展开方案列表和新建入口。
- 路线顺序面板支持折叠到标题栏，方便直接操作地图。

## 3. 关键决策

### 3.1 路线顺序优先

路线顺序是移动端的主要业务面板。面板位于底部搜索上方，采用稳定最大高度和内部滚动，避免控制点增加时推动地图或搜索栏。逐段导航入口与路段选择并列，点击导航时同时选中对应路段。

### 3.2 统一外部导航 URI

`createMapNavigationUri` 统一负责供应商参数和坐标顺序：

- 高德使用官方 `https://uri.amap.com/navigation`，设置 `callnative=1`，移动端优先尝试调起高德 App，失败时由官方网页承接。
- 腾讯使用官方 `https://apis.map.qq.com/uri/v1/routeplan`，按腾讯要求使用“纬度,经度”的坐标顺序。

路线顺序与桌面路线摘要复用同一个生成器，避免供应商切换后仍打开高德。

### 3.3 折叠不改变地图尺寸

地图供应商控件通过绝对定位保持右侧锚点，选项只向左展开；方案入口、搜索结果和路线列表均覆盖在地图上，不参与地图容器文档流。移动端不渲染可见地形面板，为路线顺序和搜索预留稳定空间，目标 CLS 为 0。

### 3.4 路线顺序默认收起

路线顺序虽然是移动端最重要的业务面板，但常驻展开会遮挡大面积地图，影响平移、缩放和选点。最终交互确定为默认收起：首次显示时只保留 `58px` 标题栏、控制点数量和展开箭头；用户需要查看或编辑路线时再主动展开。折叠只改变呈现状态，不卸载排序上下文，不清空滚动位置、当前控制点或当前路段选择。

## 4. 功能变化

- 搜索栏使用底部安全区，加载、空结果、失败和候选列表均在输入框上方显示。
- 地图供应商默认只显示图层图标，展开后显示“高德/腾讯”和当前状态勾选。
- 每个路段始终显示路段名称与导航图标，包括返回起点路段。
- 顶部方案选择器默认收起；未加载方案时不再自动展示大面积欢迎面板。
- 路线顺序默认折叠为 `58px` 标题栏，点击标题栏箭头后展开；列表保持挂载，再次收起与展开时保留滚动和选择状态。
- 桌面端保留现有顶栏搜索、双标签供应商 Switch、路线摘要和地形分析布局。

## 5. 降级与边界

- 高德 URI 的原生调起受系统、App 安装状态和内置浏览器策略影响；官方 URI 负责网页降级。
- 腾讯 URI 打开腾讯地图路线规划页，最终是否调起客户端由腾讯 URI 服务和系统环境决定。
- 外部地图会重新计算路段，本页面不承诺外部路线与当前折线完全一致，也不承担实时导航。
- 本次只在移动端隐藏地形分析，没有删除海拔领域状态或桌面端能力。
