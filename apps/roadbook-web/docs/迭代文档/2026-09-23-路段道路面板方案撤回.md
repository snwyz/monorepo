# 路段道路面板方案撤回

## 1. 迭代信息

- 日期：2026-09-23
- 应用：`apps/roadbook-web`
- 地图领域包：`@roadbook/map`
- 状态：方案已撤回
- 目标：取消独立的路段途经道路面板，仅保留现有路线摘要。

## 2. 撤回原因

- 独立道路面板重复展示了路线摘要已有的路段总里程和预计驾驶时间。
- 地图服务返回的道路步骤数量较多，长途路段可能产生近百条记录，增加地图遮挡和信息负担。
- 分道路行车时间由距离比例估算，无法反映不同道路速度与拥堵差异，容易形成不准确的精细数据印象。
- 当前核心任务是路线结构、总里程、总耗时、红绿灯和外部导航，现有 `RouteMetricsPanel` 已覆盖这些信息。

## 3. 功能变化

- 删除 `RouteRoadPanel` 及全部对应样式。
- 删除高德和腾讯适配器中的道路步骤解析与道路汇总模型。
- `DrivingRouteLeg` 恢复为只保存路段距离、预计耗时、红绿灯数量和轨迹。
- 产品、UI 与组件规范恢复为只描述现有路线摘要。
- 路段选择后只展示 `RouteMetricsPanel`，内容包括总里程、预计驾驶时间、红绿灯、路线状态和外部导航。

## 4. 验证结果

- `@roadbook/map` 类型检查与构建通过。
- `roadbook-web` ESLint 与生产构建通过。
- Git diff 格式检查通过。
- 构建自动改写的 `next-env.d.ts` 已恢复，不进入本次变更。

## 5. 后续设计输入

用户提供了地图控制点标签草图，期望每个坐标在地图上展示编号和地点名称，并通过引导线连接真实坐标。该需求已转入独立的“地图控制点名称标签迭代”，不与已撤回的道路面板复用状态或组件。
