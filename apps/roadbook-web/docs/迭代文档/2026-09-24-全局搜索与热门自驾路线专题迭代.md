# 全局搜索与热门自驾路线专题迭代

## 1. 迭代信息

- 日期：2026-09-24
- 状态：已完成
- 完成日期：2026-09-24
- 应用：`apps/roadbook-web`
- 地图领域包：`@roadbook/map`
- 目标：把顶部地点搜索升级为全局搜索与发现入口，并新增只读“黄金大环线”热门自驾路线专题及本机个人标记能力。

## 2. 范围

本轮包含：

- `Closed → Discovering → Filtering → PreviewDialog` 全局搜索状态机；
- 最近搜索、分类标签、热门路线推荐卡、地点与热门路线过滤；
- 桌面 `Cmd/Ctrl + K`、`Escape`、方向键和焦点恢复；
- “黄金大环线”预览 Dialog 与 URL 查询参数同步；
- G219、G331、G228 三条受控颜色概览图层；
- `164` 个官方主要控制点的分层标签、定位和外部地图导航；
- 专题模式搜索或双击添加“我的标记”，并按专题保存到本机；
- 高德与腾讯地图独立图层适配；
- 桌面和移动端顶栏、蒙层、面板与专题列表响应式布局。

本轮不包含：

- 可直接用于导航或测绘的权威道路中心线；
- 用户修改官方专题路线；
- 专题线路重新算路、里程或耗时统计；
- 把专题一键复制为个人路线方案；
- 云端热门路线目录或个人标记同步。

## 3. 关键决策

### 3.1 热门路线与个人规划隔离

热门路线使用 `FeaturedDrivingRoute` 独立领域模型，不写入 `RoutePlan`，不受普通规划的 `20` 个控制点、闭环重算、拖拽排序或自动暂存流程影响。专题打开时暂时隐藏个人规划图层，但不删除、不覆盖后台已保存的活动方案。

### 3.2 官方内容只读，个人标记可编辑

专题线路和官方控制点只读。用户通过搜索或地图双击创建的是 `FeaturedRouteUserMarker`，只支持定位、删除、清空和外部导航，不改变线路、不重算指标。个人标记最多 `20` 个，并按专题 ID 隔离保存。

### 3.3 地图图层分离

`WebMapCanvas` 新增热门路线概览线、官方控制点和个人标记三个设置入口。高德与腾讯适配器分别维护国道主线、低缩放国道编号、放大后的控制点标签和个人标记图层；专题图层不复用个人规划控制点 Marker。

### 3.4 分层标签

- `zoom < 7`：隐藏控制点标签，只沿线路显示分散的 `G331`、`G219`、`G228` 国道编号。
- `zoom ≥ 7`：隐藏国道编号，显示当前视野中的官方主要控制点标签。
- 点击右侧控制点时将地图定位到该点并切换到 `zoom 9`，确保对应标签可见。
- 控制点分为县市、明确口岸和景区；不再维护或展示“附近中心城市”。
- 右侧控制点目录始终展示 G331 的 `37` 个、G219 的 `52` 个和 G228 的 `75` 个控制点，不受地图缩放影响。

### 3.5 按官方控制点生成道路级概览几何

路线控制序列采用国家发展改革委发布的 2022《国家公路网规划》附表中 G331、G219、G228 的主要控制点，不再直接连接少量展示城市。生成脚本逐段请求地图驾车规划并优先选择命中国道编号或国道路名的候选线路，再进行轻量折线简化；G228 按丹东、东港、庄河、大连、营口、葫芦岛、秦皇岛等陆路控制点绕行渤海，不连接烟台与大连的海上直线。

该数据仍是专题展示用道路级概览几何，不是交通主管部门发布的道路中心线，也不作为里程、耗时或实时导航依据。运行时仅在用户确认打开专题后延迟加载几何 JSON，避免约 `754KB` 的资源进入首页关键加载链路。

### 3.6 地图服务限流

高德 Web API 的账号级并发上限为每秒 `3` 次。离线生成器使用全局串行调度，每次地图服务请求至少间隔 `400ms`，峰值约每秒 `2.5` 次，并仅对瞬时服务端错误执行有限次退避重试。不得把不同国道或路段改为并发生成。

## 4. 功能变化

### 4.1 全局搜索

- 关闭态为顶栏中央浅灰胶囊；发现态扩展为白色搜索条并显示不使用背景滤镜的中性蒙层，蒙层在过滤态继续保留。
- 查询为空时依次展示最近搜索、分类标签和热门路线推荐卡。
- 没有历史记录时不展示空的“最近搜索”分区；分类数量仅在大于 `1` 时展示，避免重复单例数字干扰浏览。
- 输入首个非空字符进入过滤态，同时搜索静态热门路线目录和当前地图供应商地点服务。
- 有效查询和打开过的热门路线写入最近搜索；历史可清空。
- 推荐图和预览图使用本地 SVG 与延迟加载，不进入首屏关键图片链路。

### 4.2 热门路线专题

- 首个专题为“黄金大环线”，采用统一高饱和冷色光谱：G331 玫红 `#FF375F`、G219 紫罗兰 `#BF5AF2`、G228 电光蓝 `#0A84FF`，并保留白色外描边；路牌与控制点标签同步使用半透明白色材质和轻量阴影。
- G331 使用 `37` 个官方主要控制点生成 `4,789` 个渲染点；G219 使用 `52` 个控制点生成 `7,727` 个渲染点；G228 使用 `75` 个控制点生成 `3,327` 个渲染点。
- 右侧专题面板按国道分组展示路线说明、图例、完整官方控制点和“我的标记”。
- 官方控制点与个人标记均可调起当前高德或腾讯地图导航。
- 国道路牌与控制点标签改为内容自适应宽度，由文字宽度和固定内边距撑开，短名称不再占用统一的宽胶囊。
- 退出专题后恢复个人规划展示。

### 4.3 响应式与布局稳定

- 桌面顶栏继续使用绝对定位，搜索展开最大宽 `600px`。
- `760px` 及以下改为固定三列顶栏，搜索关闭态居中，展开态左右保留 `16px`。
- 搜索蒙层、面板、Dialog 和专题面板均脱离正文布局，不改变地图容器尺寸，目标 CLS 为 `0`。
- 横向历史、分类和推荐列表隐藏滚动条但保留触控滚动。
- 热门路线保持横向卡片目录结构，即使当前只有一个专题也不切换为纵向列表，为后续扩展专题保留一致浏览方式。

### 4.4 推荐卡路线图标

- 黄金大环线缩略图从三段分色环形示意改为一条闭合折线轮廓，折点来自专题几何的高度抽稀结果。
- 图标仅使用荧光绿、Apple 绿到青绿的小面积渐变和重复描边柔光，不使用 SVG 滤镜，不展示地图、节点、国道编号或图内文字。
- 推荐卡在“黄金大环线”下展示领域元数据“约 `28,300 km`”；不在首屏加载道路几何，固定尺寸保持 CLS 为 `0`。
- 路线名称与约整里程在缩略图下方统一水平居中，避免图形居中而文字左偏的视觉断层。

### 4.5 Apple 风格视觉校正

- 问题根因是搜索发现态同时使用大面积背景模糊、`24px` 内容面板圆角和重投影，把材质效果叠加成了主要层级信号，并与 UI 规范中的性能克制原则冲突。
- 搜索蒙层改为暖白半透明实色，不再使用 `backdrop-filter`；发现态和过滤态共享蒙层，避免输入首个字符时背景突然改变。
- 搜索条与内容面板间距统一为 `12px`，面板圆角统一为 `16px`，边框和阴影复用正式 Token；快捷键提示提高字号与对比度。
- 保留热门路线横向滚动目录的产品意图，不因当前单卡状态改成全宽纵向推荐项。
- 本次仅调整展示层和可访问焦点顺序，不修改全局搜索状态机、领域数据、历史仓储、专题加载或地点搜索行为。

### 4.6 移动端搜索安全区校正

- `410 × 672` 移动视口截图中，展开搜索仍呈现约 `240px` 的顶栏网格列宽，分类项被裁切在面板内边距之前。根因是展开态依赖固定定位元素的 `left/right + width:auto` 隐式宽度求解，实际 H5 运行环境未稳定脱离顶栏网格约束。
- 移动端展开态改为由视口宽度和左右安全区显式计算，不修改桌面最大宽度、搜索状态机或业务数据。
- 搜索面板高度同时扣除顶部、底部安全区，并保留 `100vh` 回退和 `100dvh` 增强；历史、分类和推荐横向目录延伸至面板尾部内边缘，保留 `16px` 收尾空间。
- 本次只改变固定浮层自身尺寸和滚动边界，不参与地图文档流，不新增图片、字体或滤镜，LCP 不增加关键资源，CLS 目标保持 `0`。

## 5. 降级策略

- 地图服务不可用时仍可打开全局搜索、查看热门路线目录和预览 Dialog，但地点搜索显示不可用原因。
- 搜索历史或个人标记本地存储不可写时，不阻断当前会话中的搜索和专题浏览。
- 地址解析失败时保留个人标记坐标并显示“未识别地址”。
- 道路几何加载失败时保留专题预览并显示错误，不进入空白专题；不计算或伪造里程、耗时和道路级导航。

## 7. 已知边界与后续建议

- 当前三条国道由官方主要控制点与地图驾车规划生成，适合全国专题展示，但仍不适用于测绘、道路级导航或精确里程统计。
- 桌面端外部导航仍使用地图 App Scheme，没有网页导航回退。
- 后续如需更高精度，应引入经过授权和坐标校验的交通行业道路中心线，并按视图层级加载简化或详细几何。
- 第二阶段可评估“基于热门路线创建我的规划”，但必须通过显式复制建立新的个人 `RoutePlan`，不得直接编辑专题聚合。

## 8. 迭代结论

黄金大环线第一阶段只读专题已完成并收口。最终交付包括：

- 全局搜索与发现状态机；
- 热门路线预览、URL 状态与延迟加载；
- G331、G219、G228 道路级概览几何；
- `164` 个官方主要控制点及县市、口岸、景区分类；
- 按缩放层级切换的 Gxxx 路牌与控制点标签；
- 高德、腾讯双地图专题图层；
- 官方控制点外部导航和本机“我的标记”；
- 冷色高饱和专题配色、白色外描边和内容自适应标签；
- 生成脚本、数据校验、限流约束与维护说明。

本阶段不再继续扩展功能。后续需求应作为新的迭代立项，不在本记录中追加第二阶段能力。长期维护规则见 `apps/roadbook-web/docs/黄金大环线数据与图层维护说明.md`。
