# 地图覆盖物 Apple 风格视觉迭代

| 项目 | 内容 |
| --- | --- |
| 日期 | 2026-09-24 |
| 范围 | 普通规划路线、控制点 Marker、路线顺序列表、屏幕中心点与用户位置点 |
| 状态 | 已完成 |

## 1. 目标

参考用户提供的移动导航截图，将 Roadbook 地图覆盖物调整为更清晰、克制且具有 Apple 地图气质的视觉层级，同时保持现有领域语义、交互行为、LCP 与 CLS 不变。

本次不修改底图供应商主题、不引入实时交通数据、不调整热门路线专题色谱，也不改变路线计算和定位流程。

## 2. 关键决策

1. 有效规划路线从外到内使用白色隔离层、Apple 蓝边界层和 Roadbook 绿色内芯。
2. 绿色只表示当前有效规划路线，不表示实时路况畅通；MVP 仍不提供页面内实时交通能力。
3. 选中路段通过三层线宽同步增加表达，不仅依赖颜色。
4. 旧结果和失败路段分别保持灰色、红色虚线，不显示蓝绿双层，避免状态语义冲突。
5. 控制点 Marker 使用白底蓝色编号的普通态与蓝底白字的选中态，并通过反色编号、描边粗细和图层共同表达状态。
6. 定位点使用 Apple 蓝、3px 白环和静态柔和精度光晕，移除持续脉冲动画，减少无任务含义的注意力占用。
7. 路线顺序列表复用导航蓝的编号和选中语义，但不复制地图上的绿色内芯；Hover 保持中性，Selected 使用淡蓝背景和反色编号，首项不再使用黑色实心圆。
8. 路线顺序列表的滚动条保持中性，不跟随导航蓝；默认使用 18% 冷灰、Hover 使用 32% 冷灰，避免在白色 Widget 边缘形成近黑竖线。

## 3. 实现范围

- `packages/map/src/map-overlay-style.ts`：集中维护地图覆盖物语义颜色和路线线宽。
- `packages/map/src/amap-web.ts`：高德地图路线三层渲染与位置 Marker。
- `packages/map/src/tencent-map-web.ts`：腾讯地图路线三层渲染与位置 Marker。
- `packages/map/src/control-point-label.ts`：控制点标签普通态、选中态和引导线。
- `apps/roadbook-web/app/globals.css`：屏幕中心定位点和 Web 语义 Token。
- `apps/roadbook-web/components/route-planning/route-address-list.tsx`：移除首项专用黑色编号类，统一由选中状态控制编号反色。
- UI 规范、组件规范与 AI 稳定上下文同步更新。

## 4. 状态与降级

| 状态 | 视觉表达 |
| --- | --- |
| 有效路线 | 白色 11px、蓝色 8px、绿色 4px |
| 选中路段 | 白色 13px、蓝色 10px、绿色 6px |
| 旧结果 | 白色 9px、灰色 4px、`8px 6px` 虚线 |
| 失败路段 | 白色 9px、红色 5px、`5px 5px` 虚线 |
| 普通控制点 | 半透明白色胶囊、蓝色边框与编号徽标 |
| 选中控制点 | 蓝色胶囊、白色文字、白底蓝字编号与加粗白边 |
| 定位点 | Apple 蓝圆点、3px 白环、18% 静态蓝色外圈 |
| 路线列表普通点 | 白底、蓝色描边和蓝色编号 |
| 路线列表选中点 | 蓝底白字编号、约 8% 淡蓝行背景 |
| 路线列表连接线 | 低透明蓝色虚线；选中路段为较粗蓝色实线 |

## 5. 性能与布局

- 新增的路线内芯沿用既有路线几何，不新增网络请求或业务状态。
- 地图覆盖物继续由供应商原生图层增量更新，不改变 React 文档流，因此不会引入 CLS。
- 不新增字体、图片、滤镜脚本或第三方依赖；Marker 阴影由轻量 SVG 滤镜生成。
- 高德和腾讯切换时新增图层必须随画布销毁，避免覆盖物泄漏。

## 7. 已知边界

- 高德和腾讯底图自身颜色仍由供应商控制，Roadbook 只统一业务覆盖物。
- 当前自动化环境无法证明真实底图上的最终对比度；需要在配置有效地图 Key 的浏览器中检查浅色道路、绿色地形和高密度城区。
- 绿色内芯不读取交通接口，不得在产品文案中表述为实时路况。
