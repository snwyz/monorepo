# 全局近黑焦点框清理

## 目标与范围

去除搜索胶囊及同类页面控件的近黑焦点框，统一轻量焦点语言。扫描范围覆盖 Web 样式、基础组件、业务组件及共享地图覆盖物源码；本次修改限于 Web 焦点样式与规范。

## 问题与根因

- 全局 `--rb-color-focus` 原值为 `#0a0a0a`，按钮、链接、输入框和基础组件的焦点提示继承近黑色。
- 搜索关闭会将焦点归还入口；当浏览器匹配 `:focus-visible` 时，入口出现 2px 近黑外圈，与截图表现一致。该触发链路已由源码确认，尚未在实际页面复现。
- 沿途超充入口及面板另有直接引用 `--rb-color-ink` 的焦点规则，仅修改全局变量不能覆盖这些规则。

## 关键决策与变化

- `color.focus` 统一为冷灰 `#87939e`，保留 2px 可见键盘提示与原有焦点归还逻辑。
- 删除超充组件的近黑焦点覆盖，让其继承全局样式；通知关闭按钮明确使用共享焦点颜色。
- 重命名输入框使用共享颜色和内收焦点提示；路线列表继续使用内收提示，避免滚动区域裁切。
- 移除没有使用方的深色搜索渐变边界变量。
- 普通玻璃卡片的低透明边界、地图语义描边和开关状态保持原有职责；未将图形轮廓、加载旋转图标误当作页面装饰框删除。
- 不增加依赖、脚本或网络资源，不修改组件尺寸、排版与业务逻辑。

## 降级策略

系统强制颜色模式使用 `Highlight`。路线列表在该模式下使用真实 outline，避免系统移除 box-shadow 后失去键盘提示。

## 验证结果

- Web ESLint 通过。
- 三个改动 CSS 文件通过 PostCSS 语法解析。
- `git diff --check` 通过。
- 源码复扫未发现 Web 控件仍直接使用近黑色 Token 绘制焦点框。
- 已同步 UI 规范与组件规范；保留工作区已有的其他修改。

## 已知边界与后续建议

- 浏览器技能使用授权尚未收到，本次未进行实际页面验收，不宣称已完成截图比对或 LCP/CLS 测量。
- 获得授权后，优先检查桌面搜索关闭、Tab 切换、路线选择、重命名、超充面板及移动端搜索状态；系统强制颜色模式单独检查焦点可见性。
- 本次仅涉及样式和基础组件类名，未运行完整生产构建，未提交或推送。

## 后续还原

用户反馈上一轮移除全部焦点描边的改动影响过大，已定向撤销该轮修改，恢复冷灰焦点样式及相关规范，移除全局底色覆盖。超充入口已有后续重构，保留其最新实现，不恢复失效选择器。
