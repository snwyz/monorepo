# 路线方案卡片对齐

## 目标

修复桌面端顶部路线选择器与下方首次规划欢迎面板右边缘不对齐的问题。

## 范围

- 桌面端 `RoutePlanWelcomePanel` 宽度。
- UI 布局规范与本次迭代记录。

不调整组件结构、内容间距、移动端布局或地图交互。

## 关键决策

- 欢迎面板沿用现有 `16px` 左侧安全边距。
- 面板宽度由 `310px` 调整为 `330px`，与顶部 `RoutePlanSelector` 使用同一宽度基线。
- 移动端继续隐藏欢迎面板，不新增响应式分支。

## 功能变化

- 桌面端两张上下相邻的路线方案卡片左右边缘完整对齐。
- 面板仍为地图上方的绝对定位浮层，不改变地图容器尺寸。

## 问题与根因

顶部路线选择器固定为 `330px`，下方欢迎面板固定为 `310px`。两者左侧坐标相同，但宽度相差 `20px`，导致右边缘产生明显错位。

## 降级策略

- 本次仅修改固定宽度，不涉及异步状态或外部服务，无额外降级路径。
- 面板不参与页面文档流，不会造成地图布局偏移，CLS 目标保持为 `0`。

## 验证结果

- Next.js 生产构建通过，正常生成全部 `13` 个路由。
- `git diff --check` 通过，新文档未发现行尾空白。
- 静态尺寸核对确认：顶部 `RoutePlanSelector` 与下方 `RoutePlanWelcomePanel` 均为 `330px`，并共享 `16px` 左侧定位。
- 未调用未经授权的浏览器 Skill；真实浏览器视觉对齐保留给人工复核。

## 已知边界

- 实际浏览器视觉对齐需在桌面端视口人工复核。

## 后续建议

- 后续若统一调整左侧 Widget 宽度，应提取共享 CSS 尺寸变量，避免不同组件再次出现固定值漂移。
