# 路段拖拽插点迭代

## 1. 目标

用户点击两个相邻控制点之间的有效路线段后，显示虚线路段插入引导和中间拖拽手柄。用户拖动手柄调整位置，松手后系统在该路段中插入正式控制点并重新规划闭合路线。

## 2. 范围

- 高德与腾讯地图使用同一领域契约表达路段插入意图。
- 普通路线段和最后一个控制点返回首项的闭环路段均支持拖拽插点。
- 新点进入既有控制点列表、撤销、逆地址解析、本地暂存和路线重算链路。
- 不新增路线服务接口，不改变地图供应商切换、路线策略或本地快照格式。

## 3. 关键决策

- 拖动期间只在地图适配器内部更新虚线与手柄，不更新 React 状态，也不请求驾车算路。
- 松手后提交一次坐标，并在应用 Hook 中重新校验路段两端仍是当前方案中的相邻控制点，避免旧路线事件污染新修订版本。
- 插入点是正式 `ControlPoint`，不是独立的隐形途经点模型，因此既有排序、删除、撤销、暂存与指标链路可以直接复用。
- 普通路段在前一控制点之后插入；闭环返程段在列表末尾追加，继续保持返回首项的闭环结构。
- 控制点达到 20 个时不展示插入引导，沿用 MVP 上限。

## 4. 地图实现

- `WebMapCanvas` 新增 `setRouteLegInsertion`，`WebMapOptions` 新增 `onRouteLegInsert`。
- 高德使用原生可拖拽 Marker，并在 `dragging` 中更新虚线、`dragend` 中提交坐标。
- 腾讯 MultiMarker 没有原生拖拽配置，使用手柄覆盖物的鼠标和触摸事件配合 Map 移动事件；拖动期间关闭底图拖拽，结束后立即恢复。
- 两家地图均使用独立的虚线外描边、虚线主线和手柄图层，并在画布销毁时释放图层与事件监听。

## 5. 视觉与交互

- 引导线使用白色 `7px` 外描边、灰色 `3px` 主线与 `6px 6px` 虚线。
- 手柄固定为 `32 × 32px` 白底近黑描边圆形，内部使用四向移动图形。
- 原驾车路线在拖动期间保持可见；选择控制点、插入完成或切换方案后隐藏引导。
- 新增覆盖物不进入文档流，不改变地图和 Widget 尺寸，CLS 目标保持为 0。

## 6. 降级与边界

- 路段已经不是当前方案中的相邻关系时忽略迟到的插入提交。
- 逆地址解析失败时保留坐标并显示“未识别地址”，不撤销已插入控制点。
- 达到 20 个控制点时不提供拖拽插点手柄。
- 路线重新计算失败时保留控制点和最后一次有效路线，沿用现有错误反馈。

- 地图覆盖物手柄属于指针交互；键盘用户仍可通过搜索、地图双击、地址列表排序和删除完成控制点规划，2026-09-26 已补充列表中的显式“添加途经点”搜索入口。
- 当前松手后重新计算完整闭合路线，尚未做受影响路段的增量缓存。

## 9. 2026-09-24 取消路段选择补充

### 问题与根因

原实现的 `selectRouteLeg` 每次都直接写入路段 ID，没有相同 ID 的 toggle 规则；地图画布也没有向应用层暴露背景点击意图，因此选中路段后只能通过选择控制点间接取消。

### 功能变化

- 再次点击当前路线段会把 `selectedRouteLegId` 切换为 `null`。
- 点击地图空白处会调用统一的 `clearRouteLegSelection`，隐藏选中加粗、虚线和拖拽手柄。
- 非文本编辑状态下按 `Esc` 同样清除路段选择；输入框、文本域、下拉框和可编辑内容获得焦点时不拦截按键。
- 高德路线、控制点与手柄显式使用 `bubble: false`；腾讯对应图层使用 `isStopPropagation`，避免覆盖物点击同时触发地图背景清除。
- 虚线引导图层保持非交互，点击虚线区域视为地图空白点击并取消选择。

### 验证结果

- `@roadbook/map` 构建：通过。
- Roadbook Web ESLint、TypeScript 与生产构建：通过。
- Git 差异检查：通过。
- 高德与腾讯地图浏览器交互：待完成。

## 10. 2026-09-26 路段列表添加途经点

### 目标、问题与范围

原列表连接行只有路段选择，插点必须操作地图手柄，入口不够直观。本次在普通路段和返回起点行增加常驻“＋ 添加途经点”，保留原路段选择与地图拖拽能力。

### 决策与功能变化

- 点击后复用全局搜索并聚焦输入，显示插入路段两端地点，避免新增模态框或首屏依赖。
- 搜索选点插入两端之间；返程段追加到末尾，起点不重复创建。复用撤销、编号、自动暂存与重新算路。
- 应用 Hook 校验方案 ID、相邻关系及点位上限，拒绝失效上下文；取消或 Esc 不产生控制点。
- 常驻按钮与连接行至少 44px 高，桌面和移动端共用；不改变地图容器尺寸。

### 降级与已知边界

- 地图不可用或达到 20 点时禁用并提供原因；算路失败沿用既有旧路线与错误状态。
- 当前本地缺少 `NEXT_PUBLIC_AMAP_KEY`，真实地图地点搜索与算路联调未完成，不能据此宣称真实地图端到端验收通过。
- 浏览器使用临时页面和固定搜索候选，复用实际列表、搜索组件与应用 Hook；临时文件在验证后删除。浏览器点击自动化存在坐标命中异常，主要通过键盘完成交互验证。
- 未引入首屏网络资源；LCP/CLS 未进行量化测量。

### 验证结果

- ESLint、生产构建（含 TypeScript）：通过；环境没有 `rtk`，使用等价 `pnpm` 命令。
- 浏览器已确认普通路段搜索聚焦、键盘选点插入中间、编号更新、撤销恢复、返程段追加到末尾，取消保留原点集，以及 390px 窄屏列表和常驻按钮布局。
- 后续建议：配置地图服务后补齐真实供应商搜索、重算与指针交互验收。
