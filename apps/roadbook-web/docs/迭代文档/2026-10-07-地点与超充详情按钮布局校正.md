# 地点与超充详情按钮布局校正

## 目标与范围

按用户提供的 H5 地点天气详情、PC 超充站详情截图，校正按钮布局与操作层级，遵循现有 WWDC 视觉方向和项目黑白控件规范。超充站共享组件同时覆盖 H5；不改变导航、加入点位、删除确认或面板手势流程。

## 问题与根因

- H5 地点详情使用行内按钮和独立外边距，没有完整的操作组布局。导航与删除共用中性灰表面，玻璃材质后代选择器进一步覆盖按钮层级。
- 超充详情使用独立按钮样式：加入按钮占剩余宽度，导航按钮按内容收缩，PC 高度仅 40px、文字 11px、圆角 12px，与现有 44px 胶囊主按钮规范不一致。

## 关键决策与功能变化

- 复用既有 `Button`，保持职责边界；业务容器管理两列等宽、8px 间距，控件使用 44px 高、13px 标签和 16px 图标。
- H5 导航为近黑主按钮，删除为危险色文字和图标的幽灵按钮，点击仍打开原有删除确认框。
- 超充加入为近黑主按钮，导航为透光描边次按钮；禁用状态继续显示原因，保持尺寸。
- 移除地点容器下所有链接和按钮的通用玻璃覆盖，交由既有按钮变体表达语义。
- 键盘复核发现共享按钮的焦点外框可能继承文字色，两个操作组局部指定冷灰焦点 Token，保持原有键盘焦点环。
- 不新增依赖、字体、图像、数据请求或模糊层，不修改地图和任务面板高度逻辑。

## 降级策略

沿用现有玻璃材质的减少透明度、增强对比度与强制颜色回退，以及共享按钮的键盘焦点和禁用态。导航仍由当前地图供应商链接承接；删除取消不修改点位。

## 验证结果

- Web `lint` 通过；最终生产构建通过，包含 TypeScript 检查。构建自动改写的 `next-env.d.ts` 已恢复原有开发声明路径。
- `git diff --check` 通过。
- 本地浏览器 PC 视口 `1280×800`：超充按钮均为 `137×44px`，间距 `8px`；主按钮白字深色底，导航为 32% 白色描边表面，链接保留高德供应商参数。
- H5 视口 `390×844`：地点详情按钮均为 `162×44px`，超充按钮均为 `152×44px`；导航主按钮、危险色删除入口和图标显示正确，无文字溢出。
- H5 视口 `320×740`：地点详情按钮均为 `127×44px`，超充按钮均为 `117×44px`，文字均无溢出。
- 点击地点详情删除入口打开既有确认框，取消后仍保留两个原有途经点；没有执行实际删除或加入站点。超充加入按钮的原有禁用条件与原因提示保持不变，未通过修改用户路线模拟重复添加。
- Tab 可聚焦删除入口，实测焦点外框和焦点环均为冷灰 `rgb(135,147,158)`。
- 没有新增首屏请求、背景滤镜或媒体资源；未单独进行生产性能采样，不宣称已验证 LCP 无回退或 CLS 为 0。
