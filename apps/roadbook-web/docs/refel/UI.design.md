# Roadbook Web MVP UI Design

| 项目 | 内容 |
| --- | --- |
| 文档版本 | V0.3 |
| 文档状态 | MVP 全局 UI 基线 |
| 更新日期 | 2026-09-17 |
| 适用范围 | `apps/roadbook-web` |
| 选定方向 | E｜经典黑白 · 极简地图工作台 |

## 1. 设计结论

MVP 采用经典黑白作为全局视觉基调：暖白画布、纯白浮层、近黑主操作、中灰信息层级、轻边框与克制阴影。

黑白不是简单地只使用 `#000000` 和 `#FFFFFF`，而是通过稳定的灰阶、线宽、描边、留白和排版层级表达状态。品牌识别主要来自地图工作台的布局、路线图形和交互方式，不依赖大面积彩色。

### 1.1 核心原则

1. **地图优先**：地图始终是页面主体，Widget 只占用完成当前任务所需的空间。
2. **黑白克制**：主界面不使用装饰性渐变、彩色大底或高饱和品牌色。
3. **清晰分层**：通过近黑、正文灰、次级灰、边框灰、暖白和纯白形成信息层级。
4. **状态不只靠颜色**：选中、异常、不可用等状态同时使用线宽、图标、文字或线型表达。
5. **稳定优先**：Widget 尺寸提前预留；加载和展开不推动地图布局，CLS 必须为 0。
6. **性能优先**：MVP 使用实色表面和轻阴影，不依赖高成本背景模糊或大面积滤镜。

## 2. 全局色彩 Token

### 2.1 核心灰阶

| Token | 色值 | 用途 |
| --- | --- | --- |
| `color.ink` | `#0A0A0A` | 主按钮、活动路线、关键标题、焦点描边 |
| `color.text` | `#3D3D3D` | 正文、主要说明、常规图标 |
| `color.muted` | `#8A8A8A` | 次级信息、占位文案、非活动路线 |
| `color.border` | `#E7E5E1` | Widget 边框、分割线、输入框边界 |
| `color.canvas` | `#FAF9F7` | 页面暖白背景、搜索框和弱选中背景 |
| `color.surface` | `#FFFFFF` | Widget、菜单、弹层和卡片表面 |

### 2.2 辅助灰阶

| Token | 色值 | 用途 |
| --- | --- | --- |
| `color.surfaceSubtle` | `#F2F1EF` | 搜索框、悬停行、骨架屏 |
| `color.textStrong` | `#1C1C1C` | 重要数字、活动方案名称 |
| `color.disabled` | `#C7C5C1` | 禁用文字和图标 |
| `color.scrim` | `rgba(10, 10, 10, 0.36)` | 模态层遮罩 |
| `color.shadow` | `rgba(10, 10, 10, 0.08)` | Widget 阴影 |

### 2.3 语义状态色

语义状态色只用于错误、成功和警告，不作为品牌色，不大面积铺底。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `color.success` | `#2F6B4F` | 暂存成功、计算完成 |
| `color.warning` | `#946200` | 旧结果、数据不完整、需要留意 |
| `color.danger` | `#B42318` | 加载失败、不可达、破坏性操作 |
| `color.focus` | `#0A0A0A` | 键盘焦点环 |

语义色必须同时配合图标或文字。不得只通过红、绿、黄区分状态。

### 2.4 CSS 变量基线

```css
:root {
  color-scheme: light;

  --rb-color-ink: #0a0a0a;
  --rb-color-text-strong: #1c1c1c;
  --rb-color-text: #3d3d3d;
  --rb-color-muted: #8a8a8a;
  --rb-color-disabled: #c7c5c1;
  --rb-color-border: #e7e5e1;
  --rb-color-surface-subtle: #f2f1ef;
  --rb-color-canvas: #faf9f7;
  --rb-color-surface: #ffffff;

  --rb-color-success: #2f6b4f;
  --rb-color-warning: #946200;
  --rb-color-danger: #b42318;

  --rb-shadow-widget: 0 6px 24px rgba(10, 10, 10, 0.08);
  --rb-shadow-float: 0 2px 10px rgba(10, 10, 10, 0.10);
}
```

## 3. 排版系统

### 3.1 字体

```css
font-family:
  Inter,
  -apple-system,
  BlinkMacSystemFont,
  "Segoe UI",
  "PingFang SC",
  "Microsoft YaHei",
  sans-serif;
```

不强制等待网络字体后再显示首屏。数字指标使用等宽数字特性：`font-variant-numeric: tabular-nums`。

### 3.2 字号与层级

| 层级 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `display` | `28/36` | 600 | 空状态主标题，仅少量使用 |
| `title` | `20/28` | 600 | Widget 主标题、方案名称 |
| `subtitle` | `16/24` | 600 | 分区标题、关键指标 |
| `body` | `14/22` | 400 | 正文、列表内容 |
| `label` | `13/18` | 500 | 按钮、输入标签、状态标签 |
| `caption` | `12/18` | 400 | 辅助说明、数据来源、时间 |

正文颜色使用 `color.text`；关键标题和数字使用 `color.ink` 或 `color.textStrong`；`color.muted` 不用于小字号核心正文。

## 4. 空间、圆角与阴影

### 4.1 间距

使用 4 px 基础网格：`4 / 8 / 12 / 16 / 24 / 32 / 48`。

- Widget 内边距：桌面端 `16px`，紧凑区 `12px`。
- Widget 之间：最少 `12px`。
- 图标与文字：`8px`。
- 标题与内容：`12px`。
- 列表行高：普通 `44px`，双行地址 `56px`。

### 4.2 圆角

| Token | 数值 | 用途 |
| --- | --- | --- |
| `radius.sm` | `8px` | 菜单项、图标按钮、标签 |
| `radius.md` | `12px` | Widget、卡片、弹层 |
| `radius.lg` | `16px` | 空状态引导卡 |
| `radius.pill` | `999px` | 搜索框、主按钮、状态胶囊 |

### 4.3 边框与阴影

- Widget 默认：`1px solid var(--rb-color-border)`。
- 浮动 Widget：`var(--rb-shadow-widget)`。
- 地图工具按钮：`var(--rb-shadow-float)`。
- 同一层级不得叠加多层阴影。
- MVP 不使用背景模糊；地图上的 Widget 使用实色表面保证性能和可读性。

## 5. 全屏地图布局

### 5.1 页面结构

地图容器固定占满视口：`width: 100%; min-height: 100dvh`。所有业务 Widget 绝对定位在地图安全区域中，不建设第二个门户页面。

| 区域 | 组件 | 桌面建议尺寸 |
| --- | --- | --- |
| 顶部左侧 | `RoutePlanSelector` | 宽 `280–320px`，高 `44px` |
| 顶部中部 | `PlaceSearch` | 宽 `360–480px`，高 `44px` |
| 顶部右侧 | `RouteStrategySelector`、主操作 | 高 `44px` |
| 左侧 | 搜索结果或方案列表 | 宽 `320px`，最大高 `60vh` |
| 右侧 | `RouteAddressList` | 宽 `320px`，最大高 `calc(100vh - 160px)` |
| 右下 | `RouteMetricsPanel` | 宽 `280–320px` |
| 底部 | `ElevationPanel` | 左右安全边距内展开，高 `240–320px` |
| 地图边缘 | `MapControls` | `40px` 方形按钮纵向排列 |

### 5.2 布局规则

- 地图关键控制点和当前路线段不能被 Widget 长期遮挡。
- Widget 展开时优先向地图边缘生长，不推动地图容器重新布局。
- 同一时刻只展开当前任务需要的面板。
- 所有异步区域预留稳定宽高；加载时使用同尺寸骨架屏，CLS 为 0。
- 小屏设备使用底部抽屉承载列表和详情，不复制第二套业务流程。

## 6. 地图视觉语言

### 6.1 路线

地图底图颜色不受产品完全控制，因此路线必须通过白色外描边保证在复杂底图上的可见性。

| 状态 | 主线 | 外描边 | 其他表达 |
| --- | --- | --- | --- |
| 活动路线 | `#0A0A0A`，`4px` | `#FFFFFF`，额外 `2px` | 实线 |
| 当前路段 | `#0A0A0A`，`6px` | `#FFFFFF`，额外 `2px` | 更粗，不只变色 |
| 非活动/旧结果 | `#8A8A8A`，`3px` | `#FFFFFF`，额外 `2px` | `8px 6px` 虚线并标注“旧结果” |
| 加载预览 | `#3D3D3D`，`3px` | `#FFFFFF`，额外 `2px` | 轻微流动仅作加载反馈 |
| 失败路段 | `#B42318`，`4px` | `#FFFFFF`，额外 `2px` | 断线图标及错误文字 |

路线重叠时不得仅依靠颜色区分，应使用线宽、虚实、层级和标签。

### 6.2 控制点

| 类型 | 样式 |
| --- | --- |
| 起点 | `28px` 圆点，近黑填充，白色编号，`2px` 白色外环 |
| 普通控制点 | `24px` 圆点，白色填充，`2px` 近黑描边，近黑编号 |
| 当前选中 | `28px`，`3px` 近黑描边，并显示地址气泡 |
| 搜索候选 | `20px`，白底，中灰虚线描边 |
| 异常点 | 白底，危险色描边，附错误图标和说明 |

“返回起点”复用起点坐标，不创建第二个独立控制点。

### 6.3 右侧地址联动

- 地址编号与地图控制点编号一致。
- 悬停地址行时，行背景使用 `color.surfaceSubtle`，对应地图点增大。
- 选中地址行时使用近黑左侧指示条、加粗标题和 `color.surfaceSubtle` 背景，不使用大面积彩色。
- 选中相邻地址之间的连接关系时，地图突出对应路线段。
- 地址解析失败显示“未识别地址”，仍保留坐标与编号。

## 7. 组件基线

### 7.1 组件职责

| 组件 | 单一职责 |
| --- | --- |
| `RoutePlanSelector` | 展示当前方案、方案数量、新建与切换入口 |
| `PlaceSearch` | 搜索地点、展示查询状态并打开候选列表 |
| `PlaceCandidateList` | 展示和选择地点候选项 |
| `RouteAddressList` | 展示控制点地址顺序并与地图点、路线段联动 |
| `RouteStrategySelector` | 展示并切换全程路线策略 |
| `RouteMetricsPanel` | 展示里程、预计驾驶耗时及可用道路信息 |
| `ElevationPanel` | 展示海拔曲线与基础地形指标 |
| `MapControls` | 承载缩放、定位和图层操作 |
| `RouteFeedback` | 展示计算、暂存、失败和旧结果状态 |

组件命名使用领域语言，不使用 `LeftPanel`、`RightBox` 等位置型业务命名。

### 7.2 Widget

- 背景：`color.surface`。
- 边框：`color.border`。
- 圆角：`radius.md`。
- 阴影：`shadow.widget`。
- 标题使用 `subtitle`；辅助说明使用 `caption`。
- 可折叠 Widget 收起后保留稳定触发器，不改变地图尺寸。

### 7.3 按钮

#### 主按钮

- 高度：`44px`。
- 水平内边距：`20px`。
- 背景：`color.ink`。
- 文字：`color.surface`，`label` 字级。
- 圆角：`radius.pill`。
- Hover：背景 `#242424`。
- Active：背景 `#000000`。
- Disabled：背景 `color.border`，文字 `color.muted`。

主按钮每个 Widget 最多一个。典型动作是“新建规划”“加载到地图”。

#### 次按钮

- 白色背景、`1px` 边框、近黑文字。
- Hover 使用 `color.surfaceSubtle`。
- 用于“切换路线”“重试”“取消”。

#### 幽灵按钮

- 透明背景、正文灰文字。
- Hover 使用 `color.surfaceSubtle`。
- 用于低优先级操作和地图工具。

破坏性操作使用危险色文字和图标，执行前必须确认。

### 7.4 搜索框

- 高度：`44px`。
- 背景：`color.surfaceSubtle`。
- 默认无强边框，使用 `radius.pill`。
- 左侧搜索图标与输入文字间距 `8px`。
- Placeholder 使用 `color.muted`。
- Focus 使用 `2px` 近黑外环，不改变组件尺寸。
- 搜索加载、无结果和失败在候选列表中反馈，不改变输入框高度。

### 7.5 列表行

- 普通单行高度 `44px`，地址双行高度 `56px`。
- 主信息使用 `body`；格式化地址使用 `caption` 和正文灰。
- Hover 使用暖灰背景。
- Selected 使用左侧近黑指示条、较高字重和暖灰背景。
- 禁用项保留文字可读性，并说明不可操作原因。

### 7.6 指标与海拔

- 里程和耗时使用 `subtitle` 或 `title`，开启等宽数字。
- MVP 不展示通行费、收费里程或费用汇总。
- 海拔图以近黑主线和中灰参考线呈现，控制点使用编号标记。
- 海拔缺失区域使用虚线和文字说明，不伪造连续曲线。

## 8. 交互状态

### 8.1 新用户

- 暖白或地图背景上的纯白引导卡。
- 主标题：“开始规划一条自驾环线”。
- 提示：“搜索地点，或双击地图添加第一个控制点”。
- 主操作使用近黑胶囊按钮。

### 8.2 老用户未加载路线

- 不自动显示上次活动路线。
- 顶部显示“我的路线（N）”和“当前：未选择方案”。
- 地图中央提示选择一条已规划路线。
- “加载到地图”为主按钮。

### 8.3 活动方案

- 活动路线使用近黑实线。
- 右侧展示路线地址列表。
- 当前路段通过加粗路线、地址行指示条和编号同步表达。
- 暂存状态以图标、文字和必要的语义色共同表示。

## 9. 动效

| Token | 时长 | 用途 |
| --- | --- | --- |
| `motion.fast` | `120ms` | Hover、按压、图标反馈 |
| `motion.base` | `180ms` | 菜单、Tooltip、轻量状态切换 |
| `motion.panel` | `240ms` | Widget 展开、底部抽屉 |

- 默认缓动：`cubic-bezier(0.2, 0, 0, 1)`。
- 动效只改变透明度和变换，不使用会造成布局位移的高度过渡。
- 遵循 `prefers-reduced-motion`，关闭非必要动画。
- 路线加载动画不得妨碍点位编辑。

## 10. 无障碍与可读性

- 正文与背景对比度至少达到 WCAG AA。
- `color.muted` 只用于非关键辅助信息，不作为小字号正文色。
- 所有可交互元素具备可见键盘焦点环。
- 点击目标最小 `40 × 40px`，主要操作建议 `44 × 44px`。
- 图标按钮必须提供可访问名称和 Tooltip。
- 路线、点位和状态不能只依靠颜色区分。
- 地图 Widget 的文字应位于实色表面上，不直接压在复杂底图上。

## 11. 性能与布局稳定性

- 地图容器、顶部工具栏、左右 Widget 和底部海拔区提前预留尺寸。
- 首屏优先渲染地图容器、顶部工具栏和必要空状态。
- 使用系统字体回退，避免字体加载导致布局跳动。
- 图标优先使用内联 SVG，不将图标字体作为首屏依赖。
- MVP 不使用大面积渐变、背景视频、玻璃模糊或动态噪点。
- 面板内容加载使用固定尺寸骨架屏。
- 桌面端良好网络下 LCP 目标不高于 `2.5s`；实测 CLS 必须为 `0`。

## 12. MVP 禁止项

- 不引入第二套品牌主色。
- 不使用彩色大面积背景或装饰渐变。
- 不用颜色代替文字、图标和线型状态。
- 不使用玻璃拟态和高成本背景模糊。
- 不创建独立门户首页或脱离地图的方案后台。
- 不展示费用相关 UI。
- MVP 不提供暗色主题；暗色模式需要单独验证地图底图、路线对比度和全部组件 Token。

## 13. 验收清单

- [ ] 所有页面颜色均引用语义 Token，不在业务组件中散落硬编码色值。
- [ ] 全屏地图、顶部工具栏和浮动 Widget 使用同一黑白灰阶体系。
- [ ] 活动路线、当前路段、旧结果和失败路段无需彩色也能区分。
- [ ] 搜索框、主按钮和导航工具栏符合 E 方案的暖白、近黑和胶囊风格。
- [ ] 右侧地址列表与地图控制点、路线段在编号和选中状态上保持一致。
- [ ] 状态色仅用于必要反馈，并同时提供文字或图标。
- [ ] 所有交互状态具备键盘焦点和足够对比度。
- [ ] Widget 展开、加载和切换方案过程中 CLS 为 0。
- [ ] 首屏没有背景模糊、网络字体阻塞或非必要大图依赖。
- [ ] 界面中不存在通行费、收费里程或费用汇总。

## 14. 最终基调

> **暖白承载地图工作台，纯白承载信息，近黑表达主操作和活动路线，中灰建立层级；彩色只服务于必要的成功、警告和错误反馈。**
