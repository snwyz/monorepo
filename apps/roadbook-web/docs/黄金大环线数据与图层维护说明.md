# 黄金大环线数据与图层维护说明

## 1. 文档状态

- 状态：已生效
- 首次完成日期：2026-09-24
- 适用应用：`apps/roadbook-web`
- 适用专题：`china-golden-grand-loop`
- 维护对象：G331、G219、G228 路线几何、官方主要控制点、地图分层标签与专题视觉

本文是黄金大环线专题的数据和图层维护入口。产品范围以 MVP 产品基线为准，视觉以 UI 设计规范为准，组件职责以组件设计与实现规范为准。

## 2. 数据口径

路线控制序列依据国家发展改革委发布的 [2022《国家公路网规划》](https://www.ndrc.gov.cn/xxgk/zcfb/ghwb/202207/P020220712348051707026.pdf) 主要控制点整理：

- G331：`37` 个控制点，`4,789` 个渲染点；
- G219：`52` 个控制点，`7,727` 个渲染点；
- G228：`75` 个控制点，`3,327` 个渲染点；
- 合计：`164` 个官方主要控制点。

专题数据使用 GCJ-02 坐标。控制点用于专题浏览、定位和外部导航入口；道路折线用于全国级与省域级专题展示。两者都不是交通主管部门发布的测绘级道路中心线，不用于计算精确里程、耗时或页面内实时导航。

不得重新引入人工精选的“附近中心城市”。不在官方控制序列中的知名城市不得冒充国道控制点。

## 3. 数据生成与限流

主要文件：

| 内容 | 路径 |
| --- | --- |
| 控制序列与生成逻辑 | `apps/roadbook-web/scripts/generate-featured-route-geometry.mjs` |
| 几何校验 | `apps/roadbook-web/scripts/validate-featured-route-geometry.mjs` |
| 运行时数据 | `apps/roadbook-web/public/featured-routes/golden-grand-loop-geometry.json` |
| 静态仓储与控制点分类 | `apps/roadbook-web/infrastructure/featured-driving-route/static-featured-driving-route-repository.ts` |

生成流程：

1. 从脚本中的三条官方主要控制序列出发；
2. 解析每个控制点的 GCJ-02 坐标；
3. 逐段请求驾车规划，优先选择命中国道编号或国道路名的候选路线；
4. 合并路段、去除重复端点并轻量简化折线；
5. 写入带版本号、坐标系、控制点、路段和道路折线的 JSON；
6. 运行独立校验，确认控制点数量、线路顺序和相邻折线点距离。

高德 Web API 的账号级并发上限为每秒 `3` 次。生成脚本必须遵守：

- 所有请求共享一个全局串行调度器；
- 相邻请求间隔不得短于 `400ms`，峰值约每秒 `2.5` 次；
- 不得按国道或路段并行生成；
- 只对瞬时服务端错误执行有限次退避重试；
- 已有有效几何时，不得仅为页面验证重复生成。

常用命令：

```bash
pnpm --filter roadbook-web generate:featured-route
pnpm --filter roadbook-web validate:featured-route
```

生成命令会访问地图服务，执行前必须确认配额和用户授权。纯 UI、标签或文档修改不得运行生成命令。

## 4. 路线正确性门禁

每次数据变更至少确认：

- G331 不得以少量城市直线跨越东北、内蒙古或新疆；
- G228 必须经丹东、东港、庄河、大连、营口、葫芦岛、秦皇岛、天津滨海新区、黄骅港、滨州、东营、烟台等控制点沿陆路绕行渤海；
- G228 不得出现烟台至大连的跨海直线；
- G219 在新疆段必须保留喀纳斯、哈巴河、吉木乃、和布克赛尔、裕民、博乐、温泉、昭苏、温宿、乌什、阿合奇、伽师、岳普湖、英吉沙、莎车、泽普、叶城等控制点；
- 校验脚本中的相邻折线点最大距离阈值继续通过；
- 专题数据加载失败时不得进入空白地图专题。

## 5. 控制点类型

领域类型使用：

- `county-city`：县、市、旗、区等行政控制点；
- `port`：名称与数据口径明确为口岸或港口的控制点；
- `scenic`：景区控制点。

当前明确分类：

- 景区：喀纳斯；
- 口岸或港口：塔克什肯、黄骅港、射阳港、大丰港；
- 其余控制点：县市。

若要改变分类，必须先确认该名称在官方控制序列中的实际语义，再修改静态仓储中的分类集合。不能仅因某个城市拥有口岸，就把整个城市控制点改为口岸。

## 6. 地图分层规则

| 地图层级 | 展示内容 |
| --- | --- |
| `zoom < 7` | 隐藏控制点名称，沿线路显示分散的 G331、G219、G228 国道路牌 |
| `zoom ≥ 7` | 隐藏国道路牌，显示当前视野内的县市、口岸和景区控制点标签 |
| 点击右侧控制点 | 地图定位到控制点并进入 `zoom 9` |

右侧专题面板始终按 G331、G219、G228 分组展示完整的 `164` 个控制点，不受地图缩放影响。所有控制点均提供当前地图供应商的外部导航入口。

高德和腾讯地图必须保持相同的层级阈值、标签数据和选择行为。不得通过缩放事件反复销毁并重建全部标签；优先使用供应商图层或标记自身的 `minZoom`、`maxZoom` 能力。

## 7. 视觉规范

三条路线使用统一的高饱和冷色光谱：

| 国道 | 颜色 | 语义 |
| --- | --- | --- |
| G331 | `#FF375F` | 玫红 |
| G219 | `#BF5AF2` | 紫罗兰 |
| G228 | `#0A84FF` | 电光蓝 |

路线保留白色外描边，以便从浅色地图道路和行政边界中分离。国道路牌和控制点标签使用半透明白色材质、对应线路色描边与轻量柔和阴影，不使用大面积渐变或强发光遮挡底图。

标签宽度必须由内容与固定内边距撑开：

- 国道路牌：文字实际宽度＋固定水平内边距；
- 控制点：徽标＋固定间距＋名称实际宽度＋固定左右内边距；
- 个人标记：图标＋固定间距＋名称实际宽度＋固定左右内边距；
- 不设置统一最小宽度；名称超过 `7` 个字符时省略，完整名称由右侧列表承载。

县市徽标显示国道编号；口岸和景区分别显示“口”和“景”。不能只依赖颜色表达点位类型或选中状态。

## 8. 加载与性能

- 专题目录和预览不加载道路几何；
- 用户点击“在地图中查看”后才加载约 `736KB` 的几何 JSON；
- 请求使用可缓存静态资源，不进入首页关键请求链路；
- 地图和专题浮层脱离正文布局，目标 CLS 为 `0`；
- 推荐卡缩略图延迟加载，首页 LCP 不等待专题资源；
- 高德和腾讯图层独立更新，不因选择控制点重建地图实例。

## 9. 修改后的验证顺序

```bash
pnpm --filter roadbook-web validate:featured-route
pnpm --filter @roadbook/map build
pnpm --filter roadbook-web typecheck
pnpm --filter roadbook-web lint
pnpm --filter roadbook-web build
```

只有控制序列或道路几何发生变化时才需要重新执行生成命令。仅调整配色、标签宽度、图层阈值或面板布局时，从校验或对应构建步骤开始即可。

## 10. 已知边界

- 当前几何适合专题展示，不适用于测绘和实时导航；
- 道路施工、改线和临时交通管制以当前地图导航为准；
- 桌面端外部导航使用地图 App Scheme，尚无网页导航回退；
- 第一阶段不支持修改官方路线，也不支持把专题直接写入个人 `RoutePlan`；
- 用户“我的标记”只保存在当前浏览器，不同步到云端。
